# Security and admission

NO LIVE MONEY. PIT_UNVERIFIED. FORMAL_ADMISSION_BLOCKED.

The independent namespace migration is not certified by the upstream C-01 trust
root. `assert_migration_admitted()` always refuses formal admission. Identity
digests, synthetic tests and contributor-authored PASS fields grant no authority.
The existing RAW/ADJUSTMENT/STATUS/PIT/SOURCE_BINDING/FORMAL gate is retained before
the additional migration rejection. Never disable either check to obtain a demo.

The versioned independent contract is FACTORLAB_INDEPENDENT_SECURITY_V1.
`tools/security/fixed_validator.py` verifies candidate bytes without importing
candidate code. Use a separately retained copy and an out-of-band anchor digest;
candidate workflow pins, rewritten receipts, synthetic data and same-commit
checker/anchor updates cannot authorize a release. The V1 protocol implements
no approval mechanism. Its exact-byte integrity result can be PASS while its
authorization result remains BLOCKED. See `docs/security/CONTROL_MAPPING.md`
for the separate software, historical archive and independent review contracts.

The public demo generates data locally and forbids network connections. No order
gateway or Legacy trading code is distributed. Optional data adapters require
explicit use and cannot certify user-supplied files. Source-only Git diagnostics
must not substitute a different clone for the actually executing installed code.

Report a vulnerability privately to the future maintainer through a separately
verified contact. No reporting email or account is invented by this candidate.
Do not post credentials, restricted source files or security-sensitive data in
public issues. Publication and licensing review remain release requirements.
