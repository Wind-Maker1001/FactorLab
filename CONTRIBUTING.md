# Contributing

Use Python 3.14, an isolated environment, and the pinned runtime/dev requirements.
Run the explicit independent CI candidate and inspect JUnit, numerical comparisons,
distribution contents and safety refusals. Record unavailable history as BLOCKED
or NOT_RUN. Preserve old Golden, anchors and issued receipts. Never rehash an old
financial claim to approve a new implementation. No live accounts or orders.

Keep candidate factors separate from the existing fourteen-factor contract.
Document units, calendars, missingness, train/validation/test isolation and
execution approximations. Include a reproducible synthetic counterexample for
material behavior changes. Review public artifacts for paths, credentials and
restricted vendor-derived content before distribution.
