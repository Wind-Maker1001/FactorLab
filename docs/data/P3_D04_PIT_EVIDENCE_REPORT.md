## 2. 四种时间的证据合同

|字段|含义|当前可以填什么|
|---|---|---|
|effective_at|法律、交易或指数关系生效时点|按各自条款分别记录；日期级不得伪装为精确开市/收盘时刻|
|announced_at|相关版本实际对外公开时点|保留公开页面日期标签、文档落款、精确公开时间为不同证据；只有标签时精确时刻UNKNOWN|
|provider_available_at|该供应商向相应用户首次分发该版本的时点|必须绑定版本、产品、渠道、时区及历史记录；现有目标记录仍UNKNOWN|
|acquired_at|本次或既有采集取得数据的时点|沿用真实收据；重新阅读时间不覆盖首次采集时间|

2026年ZIP创建、OOXML创建、文件mtime、下载/导出、HTTP Last-Modified及本地映射available_at均不能倒推出2017/2018/2021年的供应商可得性。当前官网保留旧日期的页面也不是当年同版载荷及首次公开时刻的证明。
