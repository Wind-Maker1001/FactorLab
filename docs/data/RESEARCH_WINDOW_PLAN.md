# 首个真实历史研究窗口

基线：`d165c65a17c1ff4b7d174a063a6607589cd38522`。日期：2026-11-08。

**P3D01_PARTIAL — NO LIVE MONEY / PIT_UNVERIFIED / HFQ_UNVERIFIED / FORMAL_ADMISSION_BLOCKED**

## 推荐：先用已有五年中证500观察窗，不重新采购或下载十年整库

推荐研究范围为 **2021-09-13—2026-09-11**。它已有历史成员、行情、状态和公司行为候选，且保留了多轮定位到原件的审查结果；相比把十年导出整体接入，所需新增工作主要是精确定位缺值、解释代码边界和补足证据合同。

这是**回顾性探索窗口**，不是已完整合格的中证500收益数据集。实际边界如下：

|维度|实际支持|
|---|---|
|日期|1,211个观察日期；独立官方日历资格仍未证明|
|成员|605,500条历史成员日，932个交易代码；不是932个已认证稳定证券ID|
|行情候选|BigQuant覆盖930个候选代码；1,091,414条窗口内行情，包含非成员期间记录|

### 可使用的因子与模型

1. 首批只做价格量能类诊断：滞后价格变化、滚动波动、均线偏离、量额变化等。原价跨公司行为的跳变不能当作经济收益；未认证的调整价只能在明确标签下作为比较输入，不能冒充因果总收益。
2. 先解释BigQuant单位、价格基准、停牌和日期语义，再做换手率、流动性与涨跌停相关特征。现有字段类型不是单位证据。
3. 财务价值/质量/成长、行业/概念暴露、资金/情绪类不进入首批历史绩效比较。对应的版本、分类历史与available_at尚未闭合；已有表可以做静态描述或来源核对。
4. 初始模型选简单确定性基线和线性/树模型的离线接口实验；软件已有Model Factory V2、Walk-forward、Registry V2与分区计算入口，可在满足各自数据/资格合同后复用。软件存在不等于这些真实候选现在能直接进入受门禁保护的训练评估路径。
5. 时间切分保持先训练后验证，预热只向过去读取；先做2022—2024训练、2025验证、2026-01-01—2026-09-11保留观察的候选切分，2021剩余部分用作预热。该切分是后续实验建议，本轮未运行或选择收益最优参数。

## 最小两源校准窗口：中国石油2017—2018

若首要目的是尽快建立一个最窄、价格质量最清楚的真实输入基线，优先复用 **601857.SH，2017-01-03—2018-12-28** 的现有候选：

- 两个来源各487个日键，日期完全相同，OHLC/volume逐值一致；CSMAR候选无缺值、无重复、无基础价格异常。
- 2017年已有244条预热观测；2018年243条研究观测及双均线信号已有收据。不必重新下载2018或重复均线历史测试。
- 2017—2018共4条现金候选和4条因子观测已有原生关联；2018两次分红已保存官方实施公告。公告落款与供应商Annodt相差一天，保留差异。
- amount有4个微小数值差异。本轮不将它们归因为已证明的浮点/舍入规则，也不选覆盖源。
- 最小补证限于：该证券的独立日历与历史身份/状态；这两年全类别公司行为全集及取消更正/空结果收据；缺失的登记/支付条款；历史供应商可得与修订链；算法/绝对锚点/精度合同及税务、执行资格。

这个窗口适合用来校准读取、公式、字段比较和公司行为账本的输入关系。两年原价对照并不能批准HFQ或收益；现有manifest仍明确action_coverage=PARTIAL、calendar=OBSERVED_SECURITY_SESSIONS_ONLY、execution=BLOCKED。若只按既有2017预热/2018研究合同使用，它是**一年研究加一年预热**，不能夸大为已经完成两年策略回测。

## 最小成本补证排序

1. **先用本地已有数据解决工程缺口**：精确缺键/空值定位、候选事件字段对照、已有公告重用和来源字典查阅。费用不必先投入整库采购；尚未取得报价，现金成本和工时保持UNKNOWN。
2. **共享合同优先**：查询/API/过滤条件、字段单位、历史分发和修订合同、授权范围、独立日历。这些可能覆盖整个窗口，但单独一项闭合不代表其余门禁通过。
3. **边界身份优先**：起点完整成员、600068相关过渡、300114/302132身份映射。只索边界主表和必要样本，不盲目索全历史价格。
4. **按最窄可用窗口补公司行为**：先601857两年全类别证明；若进入五年多证券研究，再按已有分组请求扩展。不要重新索已保存的两份中国石油公告，也不要用“无股本变化行”证明无送配事件。
5. **最后扩范围**：只有在缺值/历史身份/事件合同可处理后，才考虑十年全市场。现有近十年导出的行数、查询窗和schema不足以支持正式十年结论。

现存资料能解决数值与字段定位，不能凭重算产生缺失的历史可得时间、独立原始来源或完整修订链。需要补充数据的仅是这些明确缺项，而不是重下已在磁盘上的整库。
