# P3-D03：调整关系与持有人收益分离

**P3D03_PARTIAL — NO LIVE MONEY / PIT_UNVERIFIED / HFQ_UNVERIFIED / FORMAL_ADMISSION_BLOCKED**

本文件是四个现金事件的候选算法诊断，不是供应商算法认证或绝对HFQ证书。事件范围、公告和时间冲突见 [证据表](P3_D03_ACTION_EVIDENCE.md)。数值沿用既有定向诊断并以当前候选前收盘复算，未重跑全市场审查。

## 1. 可手算的现金除息候选

令事件前原价收盘为P、每旧股税前现金为D。在**只有该现金事件**、无其他同时行为的假设下：理论除息参考价 `E=P-D`；局部向前调整比率 `q=E/P`；局部向后调整比率 `b=P/E=1/q`。这是价格连续化候选，不是现金实际再投资，也不约束真实市场开盘价等于E。

|除息日|P（CNY）|D（CNY/旧股）|候选 q|候选q−CS FwardFactor|
|---|---:|---:|---:|---:|
|2017-06-22|7.72|0.03801|0.9950764248704663212435233161|+4.2487046632e-7|
|2017-09-15|8.03|0.06926|0.9913748443337484433374844334|−1.5566625156e-7|
|2018-06-21|7.42|0.06074|0.9918140161725067385444743935|+1.6172506739e-8|
|2018-09-21|8.96|0.08880|0.9900892857142857142857142857|+2.8571428571e-7|

四条都与CS展示的六位小数因子相容，但仅能说数值相容；不知道内部精度、现金小数保留、取整时点、复合行为排序和修订处理，不能据此指定正式公式。

2018-06-21的具体算式：`E=7.42−0.06074=7.35926`；`q=7.35926/7.42`。登记日持有100股，税前权益6.074元。若仅为解释除息而假设原价恰好跌到E，则市值735.926元、应收6.074元，总值仍742元。除息日确认应收，发放日应收转现金；两日期相同也不能消灭现金流分类。金额6.074元是未按账户结算取整的算术权益，实际分币结算规则仍待合同。

登记后卖出不自动丧失已确认权益；除息日新买入不能领前日权益。真实持有人税前总收益需要原价市值、股份数、现金/应收和外部净现金流，不能以复权价收益再加一次分红，否则重复计数。未知税务不以税前替税后。

## 2. 两源因子不属于可互换输入

CS有4行、每行分别给FwardFactor/BwardFactor及累计字段；BQ有8行、按type拆分，method均为`price_gap`。按同日期比较，四组forward和backward全部不相等，差异见 [机器摘要](p3-d03-summary.json)。

|2017-06-22|−0.0002573471502591|+0.0002603333333333|
|2017-09-15|−0.000092310087173|+0.000093969849246|

另一个可人工对照的候选：先将每股现金四舍五入至分，再用 `(P−rounded(D,2))/P`。四个现金分别变为0.04、0.07、0.06、0.09，其候选比率分别约为：

- 2017-06-22：0.9948186528497409；
- 2017-09-15：0.9912826899128269；
- 2018-06-21：0.9919137466307278；
- 2018-09-21：0.9899553571428571。

这些关系与BQ数值接近，提供了一个需要合同核对的精度/参考价候选。不能判定BQ真的先舍入现金：也可能使用已舍入除息参考价、其他price-gap定义或其他输入。四个案例不能区分上述算法，不能选择残差最小者作为正式规则，也不能把真实分红权益改成分位近似。

`Adjprcwd` 的已审字典含现金红利再投资的可比价语义；它不自动等于本文件的简单price-gap链，也不等于实际持有人税后总收益。两个供应商是否同一再投资假设、同一税制、同一参考价和同一锚点，均UNKNOWN。

## 3. 累积方向、原价与锚点

在明确采用上述局部ratio候选时，以第一事件之前的局部锚点1为例，后复权乘数沿时间向后为 `B_t=∏(1/q_i)`；原价 `P_t` 乘B可形成局部后复权序列。若将终点锚定为1，前复权乘数对更早日期为其后事件的 `∏q_i`。原价不乘这些因子，是成交、持仓估值和现金账本的基础输入。

前复权会随锚定终点/后来事件改变更早价格，不得把2026导出的当前前复权链直接作为2018已知信号输入。后复权名称也不保证PIT：晚到修订同样可改变历史乘数。四事件局部链不包含更早事件、不能给绝对历史价格锚点。

CS累计字段与单次因子不能混用。既有四观察中CumulateBwardFactor依次上升，符合正现金事件下后向乘积的候选方向；累计前向字段的观察不能只用窗内四现金、局部锚点1解释。缺少窗口外事件、锚定规则和更新时点时，保持绝对锚点及正式累积合同UNKNOWN。

本轮候选公式用Decimal40位计算，输入原生字符串或浮点十进制表示；摘要残差是诊断值。CS单次因子展示六位小数、BQ二进制浮点表示，不证明内部精度。不得把六位展示精度当正式误差阈值；每股、每账户、每天/每事件、乘法前后的舍入规则须分别补证。

## 4. 非现金行为的经济账务（条件示例，不指称实际发生）

|行为|持股与现金|候选理论除权关系|仍需补证|
|---|---|---|---|
|送股s、资本公积转增c（每旧股）|数量从N变为N(1+s+c)，现金分红另列；到账与可交易日期不能用除权日代替|无其他行为时 `E=(P−D)/(1+s+c)`|权利归属、数量取整、股份到账/上市日、税务|
|配股r，认购价K，假设全额认购|旧股N对应认购rN，支付KrN，获新股rN；未认购、部分认购、权利交易各不同|全参与且无其他行为时 `E=(P−D+rK)/(1+r)`|认购开始/截止、缴款、参与决策、权利处理、到账/上市日；不能只改价格不减现金|
|拆并股比例k（新/旧）|数量Nk；非整股处理另列；不自动有现金流|无其他行为时 `E=P/k`|k方向、零碎股处理、信用及交易日期|
|股本存量变更|不能仅凭总股本差推算旧持有人数量|无通用可认证公式|增发对象、股份类别、实施条款及稀释语义|

这些是解释和人工核算关系，没有扩展执行器，也没有把无记录变成零行为。送转/配股/拆并的复合行为先后顺序与权利基数不明时，不能机械套组合公式。

## 5. 验收解释
