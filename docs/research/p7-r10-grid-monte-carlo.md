# P7-R10：动态 Grid Monte Carlo 尾部风险压力测试

**NO LIVE MONEY · 压力测试，不是盈利预测或财务准入。**

## 研究定义

使用 GPU-03 的 `MonteCarloRunner` 生成 GBM 与 Moving Block Bootstrap 资产价格路径，将完整资产价格而非固定权重组合 VaR 输入现有 `GridExecution` / PaperBroker / TradingController。Grid 的现金、库存、订单、成交成本及 NAV 均由 Paper 账户更新。固定权重、逐步再平衡、零成本的 Monte Carlo 组合结果只作为生成收据，不作为 Grid 结果。

冻结原始小时等比 Grid：初始总权益 1,000 USDT，零库存，价格锚 204.34，区间 163.472–245.208，8 层，每单 0.10，库存上限 1.00，breakout=pause；其余参数引用 `configs/grid_paper_nvda_hourly.json`。采用既有 4/6 bps 手续费/滑点。不引入未合并 R09 实现，不搜索最优参数。

## 输入与时间边界

复用 R04B 认证快照 `352d960fad24e50f1423ff173d838a994a29603d2629652f46c7edc76e5e2a83`，原始历史价格覆盖 `[2026-05-14, 2026-08-12)`。快照实际取得于 2026-11-13，不能据此声称本研究在 8 月已经取得数据。每条历史收益的 `available_at` 保守取观察完成与快照取得时间的较晚者；参数估计截止 `2026-11-14T00:00:00Z`，情景从 `2026-11-15T00:00:00Z` 开始。

GBM 以小时为单位，dt=1；对数收益均值加半方差估计 drift，样本对数收益标准差（ddof=1）估计 volatility。Bootstrap 使用相邻完整小时简单收益、24 小时移动块。两者使用同一冻结历史收益样本，价格锚采用冻结 Grid 初始价格，模拟路径不是历史行情延伸或未来价格预测。

## CLOSE_ONLY_SCENARIO

情景只有顺序收盘价，没有历史 OHLC、盘口、成交量或真实撮合证据。禁止为满足输入合同补造 high/low/volume；ATR 模式拒绝此输入。策略可以观察完成的 close-only 小时，但只允许更早提交的订单在后续收盘报价尝试成交，不允许同观察提交并成交。

每个账户每小时共享固定**合成数量容量**：基础 0.10，压力 0.01。这不是市场成交量，也不是估计的盘口深度；真实最小数量、名义金额及现有 fill admission 仍然生效，因此小容量不保证能部分成交。容量不足或入场拒绝导致的少交易、低回撤不能解释成策略更安全。未完成退出保留在期末库存与权益中，不强制虚构平仓。

资金费为 **NOT_SIMULATED**，没有真实未来资金费输入。现金基准无收益；固定持仓基准以初始权益全额赋予固定头寸，零换手、无交易成本，不冒充首步可成交订单。它们是资本基准，不是等实际风险暴露比较。

## 数值与证据

逐小时最大回撤包含初始权益。loss=`1-terminal_NAV/1000`，负损失为收益；VaR 使用线性分位数，CVaR 是最差 `(1-confidence)*n` 个损失的加权均值，边界采用分数观察，与 GPU-03 共享归约实现。FIFO 复用既有权威 Paper 归因：闭环净收益只计完全消耗且未受风险退出污染的 BUY lot，残余库存计入买入成本与已发生费用，不虚构期末卖出成本。

连续下跌、缓慢下跌、长时间低波动、横盘后跳跌、下跌后反弹不足、快速反转是单列的确定性价格压力输入，不纳入 GBM/Bootstrap 概率分布。

每次只在内存中持有一小批完整价格路径。随机种子按批次递增，批次规划是实验身份的一部分；它不等同于单次相同 seed 大运行的随机流。临时 Paper SQLite 在归因后删除；只导出每路径汇总与少量最差终值路径的价格、小时账户和成交证据，不在 SQLite 保存全部情景价格。

必须区分：快照是原始历史观察；Monte Carlo 输出是模拟价格；Paper fill 是合成成交；本研究不产生真实交易所执行证据。

## 执行与结果

CPU 小样本账户核验已完成；新增 close-only 测试及 Monte Carlo、Paper 数值合同回归共 101 项通过，另一次 Grid 执行相关测试 53 项通过（集合有重叠，不相加）。每模型 16 条、168 小时的分布实验已完成，分布、尾部场景及性能证据见 [summary.json](../validation/p7-r10/summary.json)，逐路径结果见 [paths.csv](../validation/p7-r10/paths.csv)。加强的逐小时回撤与未完成退出账户测试另有 7 项通过。

### 动态账户结果

基础容量 0.10，初始权益 1,000 USDT；VaR/CVaR 为95%水平的权益损失比例：

| 模型 | NAV 5%分位 | NAV 中位 | NAV 95%分位 | Grid VaR | Grid CVaR |
|---|---:|---:|---:|---:|---:|
| GBM | 998.8991 | 1000.0000 | 1000.6711 | 0.11009% | 0.11811% |
| Bootstrap | 998.7798 | 1000.0000 | 1001.0768 | 0.12202% | 0.19554% |

16条路径下95%尾部质量只有0.8个观察，分数CVaR退化为最差一条损失；不能将其视为稳定的罕见事件概率估计。最差GBM路径期末998.8189、库存0.10、最长持有约145小时；Bootstrap最差路径期末998.0446、库存0.20、最长持有约155小时。现金始终1000；全额固定持仓的VaR分别7.7019%和7.9079%，CVaR分别8.0629%和9.3379%。Grid实际暴露远低于全额持仓，不能据此宣称等风险优势。

0.01容量档全部路径没有成交，NAV均为1000：这是成交准入与最小名义金额限制下的不可执行情景，不是无风险策略。

### 六类确定性压力

| 路径 | 基础容量期末权益 | 最大回撤 | 期末库存 | 解释 |
|---|---:|---:|---:|---|
| 连续下跌40% | 970.7181 | 2.9282% | 0.50 | 五次买入形成残余损失29.2819，无闭环 |
| 缓慢下跌15% | 995.6917 | 0.4308% | 0.20 | 缓慢积累仍有残余损失4.3083 |
| 长时间低波动 | 1000.0000 | 0% | 0 | 未触达网格，不产生收益 |
| 横盘后跳跌30% | 1000.0000 | 0% | 0 | 现有突破暂停与成交准入阻断买入，不能解读为所有跳跌均无风险 |
| 下跌35%后仅反弹至78% | 989.0681 | 2.4174% | 0.50 | 反弹降低回撤但未清除10.9319残余损失 |
| 快速反转 | 1003.2201 | 0.4922% | 0 | 六次成交完成闭环净收益3.2201 |

这些路径表明库存能在没有闭环收益时持续承受价格风险；反弹幅度不足并不等于账户恢复。原始pause策略没有风险退出不能被描述为退出成功；独立冻结账户测试验证exit策略可因容量限制保留未完成退出。

完整研究耗时598.882秒，其中Paper账户与归因598.582秒，价格生成0.002495秒；进程峰值RSS约167.1MiB。每批8条资产路径仅10,816字节，另有生成器参考路径和工作区。所有路径FIFO权益对账残差绝对值不超过1e-24。证据只保留每组最差终值路径，随机批次种子710/711、批量8；不扩大到十万条完整路径。GPU 仅用于价格生成，Grid 逐路径执行仍在 CPU；生成时间包含 Runner 内的传输与固定权重参考归约，不能解释为纯核函数时间或全流程加速倍数。

同一 Python 3.14 / NumPy / CuPy 环境下，每模型 256 条、168 步，按 16 条分批的独立价格生成对照：

| 模型 | CPU 总秒数 | GPU 总秒数 | GPU 首批秒数 | 后续15批 GPU 秒数 | 终值均值差 / 合并标准误 |
|---|---:|---:|---:|---:|---:|
| GBM | 0.01053 | 0.46884 | 0.43274 | 0.03610 | 1.17 |
| Moving Block Bootstrap | 0.01032 | 0.04719 | 0.00934 | 0.03786 | 0.88 |

该有界小规模下 GPU 更慢；不同随机流的均值差在约 1.2 个合并标准误以内，仅作为统计一致性诊断，不宣称逐值相等或完成模型验证。进程峰值 RSS 约 562 MiB，包含 CUDA 运行时；私有 GPU 池的预算与峰值另见生成收据，不等于显卡总占用上限。没有据此扩大路径规模或重写交易引擎。
