# MC-05-F06：静态网格多模型尾部精度研究

## 实验协议 v1

金融参数来自 `configs/mc05_grid_tail.json`，F06 调度定义为 `configs/research/mc05_f06.json`。初始权益 1000 USDT，NVDAUSDT 历史小时收益校准，固定几何网格、4 bps 手续费、6 bps 不利滑点、0.10 合成数量容量；资金费率不模拟。结果不是永续合约真实净收益，也不是交易准入。

旧完整 Paper 研究、F06 六位小数报价批量研究、真实历史行情回放和历史校准下的合成随机路径是不同实验。本研究属于最后一种；所有报价先冻结六位小数，再交给批量执行和独立 Paper，不声称重现旧路径。校准快照的完整身份必须与冻结定义一致。

主实验四模型 GBM、24小时 Moving-block Bootstrap、MC-03 v1 Regime Historical、MC-03 v1 Jump-down；每模型五种子，168小时，10k/100k/1M 账户。Jump 每小时事件概率1/168、幅度30%下跳是压力假设，不是市场概率。720/2160小时根据主实验实测成本和精度选择档位，各周期为独立随机总体。

## 随机身份与嵌套

旧 `seed + batch_id` 在 batch8、7920路径时已使1729/2718重叠，不用于F06。F06 将 `(model_slot,horizon_slot,seed_slot,chunk_id)` 无损编码为 uint32 整数，在有限分配域上做固定奇数乘数的可逆置换。配置固定所有槽位及置换参数；种子标签通过冻结列表映射槽位，不因选择某一子集重编号。生成与审计使用不同命名域。

有效种子身份无重复，不等于证明不同PRNG子序列数学不相交。GBM/MBB 使用现有 CPU MT19937；Regime/Jump 继续由现有生成器内部 PCG64/SeedSequence([有效种子,块内路径号]) 生成。全局路径号为块号×固定块大小+局部号。路径身份还包含协议版本、模型、根种子、周期、生成块大小和模型/NumPy版本。生成完整1000路径块后取前缀，执行批大小只切片冻结价格；因此三规模档位是同一总体前缀，不能算独立重复。每块低于现有PathPlan上限，不修改生成器或执行器。

## 预声明统计规则

所有风险量从完整路径终态精确计算，不平均批次VaR/CVaR，不删除零成交账户。损失=1−权益/1000，线性VaR、分数边界CVaR，95%和99%。总体、成交、曾持仓和终态持仓分群保留总体分母、群内分母、参与率、条件概率和联合概率；空群指标未定义。

报告净收益均值/中位数、盈利/亏损/零收益/零成交概率、回撤分布及超过20%概率、成交次数、费用、滑点、库存、终态净敞口、占用资金、策略状态。总体的终态占用不能称为全程平均/峰值。逐时资金占用与TTL后成交来自明确标记的独立随机/形态审计样本，不替代全样本风险。

95%点态模拟抽样区间：Wilson事件区间、二项秩分位数区间、均值路径标准误、满足正则条件的CVaR影响函数大样本区间。保留阈值并列、薄尾部、最大单路径尾部权重和区间退化诊断；不确定性无法解决时明确标记。小样本验证使用现有路径bootstrap作参考，百万账户不机械执行999次全量bootstrap。

嵌套差异按共享前缀处理，不用独立样本标准误；分位数差使用保守端点界。五种子离散度单列，不能混淆为市场预测区间。没有金融容差依据，不给出正式收敛或金融等价结论；固定报告精度、区间宽度、跨种子变动及嵌套差异，不按显著性挑选扩展。抽样精度不覆盖校准及模型不确定性。

旧F03与F06并列时区分协议、随机流及样本数；薄样本诊断仅说明新总体中的样本量效应，不把旧不稳定的全部原因归结为样本不足。

## TTL、审计与覆盖

TTL=100，不续期。取消申请当步仍可能成交，随后确认取消。长期停止交易不等于库存清空；库存继续按市场价格计价。

每模型/种子独立随机抽样，另选最大盈亏、典型震荡和单边路径。独立Paper逐时逐笔比对同一冻结报价，再执行文件Paper/FIFO账户归因。审计选样不估计总体概率/CVaR。异常批次逐路径识别，保存身份/报价/拒绝原因并交权威Paper，完整纳入总体或明确整体覆盖未完成，不静默删除。

## 复现入口

从仓库根目录安装 `.[dev,monte-carlo-native,monte-carlo-cuda]`，使用匹配冻结数据身份的本地快照：

```sh
python tools/research/run_mc05_f06.py --snapshot <certified-snapshot> --output local-results/formal-168 --backend cuda
python tools/research/run_mc05_f06.py --snapshot <certified-snapshot> --output local-results/formal-720 --steps 720 --sizes 10000 100000 --backend cuda
python tools/research/run_mc05_f06.py --snapshot <certified-snapshot> --output local-results/formal-2160 --steps 2160 --sizes 10000 100000 --backend cuda
python tools/research/report_mc05_f06.py --studies local-results/formal-168 local-results/formal-720 local-results/formal-2160 --output <new-compact-evidence-directory>
```

各输出目录必须不存在；先完成168小时全矩阵，再执行已确定规模的长周期。`--backend cpu`仅替换网格执行设备，不改变CPU生成的冻结报价。统计及审计成本计入各运行收据；完整价格按配置和生成块身份重建，只有审计及不支持路径保存完整报价。
