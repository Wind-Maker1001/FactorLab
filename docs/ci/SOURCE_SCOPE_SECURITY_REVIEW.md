including the previous author's complete production changes, four synthetic
test modules, package configuration and CI. Exact worktree identities are in
`source-integrity-inventory.json`; they establish software byte identity only.

the local integration audit. No V2 financial approval mechanism is introduced.

The fifteen new/modified production paths consist of the explicit CLI dispatch,
CN/US contracts/adapters/calendars/identity/data/factor/research/accounting code,
deterministic US fixture and isolated scenario engine. The prior author's
implementation is copied from its exact Git blobs. No supplier ingestion or
historical experiment acquisition scripts are included in the new publication.

The only changed pre-existing production module is the CLI, which dispatches
the explicit cross-market subcommand. Existing factors/models, RAW, PIT, HFQ,
qualification, formal forward, admission and security modules are unchanged.
New modules introduce no eval/exec, unpickling, subprocess, dynamic module
loading or credential-bearing network calls. The data-provider API reads only
explicit caller-supplied local files; those files do not become certified data.

The scenario engine has its own result type, prefixes saved table columns,
requires a dedicated output root and rejects every formal consumer request.

artificial income never issue certified returns or financial admission.

Identity, action coverage and timestamp assertions validate structure; they do
not authenticate self-declared real evidence. Synthetic positive software
tests remain separate from actual evidence qualification.

new scope. The formal financial consumer still rejects unconditionally.
