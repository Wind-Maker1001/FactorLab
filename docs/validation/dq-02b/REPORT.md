# DQ-02B BigQuant 列式内容审计

**DQ02B_PARTIAL_RESOURCE_BOUND**

NO LIVE MONEY / PIT_UNVERIFIED / HFQ_UNVERIFIED / FORMAL_ADMISSION_BLOCKED

原始供应商数据只读。

## 内容覆盖

资产分母 10 个 ZIP，其中 9 个含 Parquet，`metadata.zip` 不含 Parquet。实际读取61 张逻辑表的 3201/3201 个 Parquet 分片，共 450,958,087 行。读取 Arrow batch 和各 row group，逐分片核对实际行数与 footer；元数据单独不计内容完成。未完成分片 0 个。分片身份绑定归档大小/mtime、成员 CRC/大小及执行代码 SHA256；这不是完整归档 SHA256 重验。

字段统计保留 Arrow 类型、null、浮点 NaN/Inf、空字符串、负值、零值及有限数值/时间极值。NaN/Inf 涉及 181 个字段—分片；负数和零不自动认定经济错误。物理 schema 多版本涉及 0 张表。详细分母见 CSV。

## 精确候选键

20 张表完成候选键的实际值精确分组；16 张表受资源/恢复范围限制，25 张表缺明确键合同。候选重复不等于业务错误，也不区分整行相同与非键字段冲突。键投影在内存中保留，单表上限 64 MiB；不存完整行、不建立 SQLite/数据库镜像。超限只阻断键检查。

精确比较观察到 `future/cn_future_basic_info` 的 instrument 候选键有 638 个重复组、674 条超额记录；未复核合约版本维度，不认定应删除。三项定向软件测试通过（0.58 秒）。

## 研究含义

继承 DQ-03 的既有研究窗口关联结论：605,500 个成员日中 BigQuant 缺键 292、缺 OHLC 564；本次字段总体统计不把这些升级为新增实际回测影响。行业体系缺失会在已检查代表月使 Join 三倍扩增；本次候选键继续保留体系维度。未重训或改写研究结果。财务版本、行业有效区间、首次公开/供应商首次可得与 HFQ 继续未认证。

## 资源与恢复

两个进程、Arrow 单线程、batch 16,384。校准 4.00 秒，扫描墙钟 3200.58 秒；各分片 CPU 合计 4315.48 秒，最大记录进程峰值 645,558,272 字节。结束时私有汇总占用 13,680,108 字节。跨进程锁串行化写前预算判断和写入；4 GiB 新增预算、80 GiB 余量。实际任务磁盘峰值、最低余量与并发总 RAM 未连续记录，不能以预算值代替实测。

恢复复用本入口同身份同代码的完整分片回执，不重复解压；恢复后的表级键检查不能从统计回执还原键，明确列为阻断，不重新扫描完整内容。旧 DQ-01 的 263 分片内容证据不具本入口全字段统计范围，因此本次补读而非升级旧证据。
