## 冻结的执行设计

[固定配置](../../../configs/research/p9-01-oos-execution.json)在首次真实账户执行前已保存，并绑定摘要 `be3269529c9ed5fceb9271c3164409c9d987e4b65001183e5ea4a918e979a5b8`。

主比较为 B FactorScore、B Ridge、B LightGBM、B XGBoost；股票基准为同候选池的固定 20 日动量和代码 SHA256 升序选股等权，另列零利息现金。所有股票方案均为每折独立 100 万元、Top10、每只目标 10%、long-only、100% 目标投资预算，不融资、不卖空。

调仓固定锚定每折 Test 的第 0 个来源会话，以位置 0、5、10…生成完整快照。缺信号/横截面不足时发全零快照，不改变日程。信号 `t` 收盘生成，下一来源会话 `t+1` 开盘执行，下一信号在 `t+5` 收盘、下一次执行在 `t+6` 开盘，对应原标签的五个开盘到开盘间隔。

只有 `t+6` 仍位于 Test 内的信号允许新开仓。之后固定日程只提交零目标，首次零目标恰在最后开仓的 `t+5`；最后不足五会话的尾部保持现金或记录无法卖出的残仓。退出失败不凭空消失，期末原价收盘估值，不用未来行情安排提前清仓。

成交始终调用既有 `AShareExecutionBacktester.run_target_weights()`，没有新建账本、撮合或费用实现。复用 T+1、整手、先卖后买、共享现金、停牌、ST/开盘价格限制及拒单。费用沿用 P8-01：佣金 3bps、最低 5 元、滑点 5bps、卖出印花税 10bps、转让费及其他方向费 0。这是研究费率合同，不是逐历史日期费用认证。

BigQuant CN 来源日历驱动执行；执行器的参考序列明确为零利息模型现金（开盘/收盘均为 1），不是伪造股票行情或市场指数。价格和状态映射仍为候选供应商语义，不升级为交易所认证。
