## 0.11 的两个解释没有混用

[鹏华公告](https://paper.cnstock.com/html/2023-05/20/content_1769923.htm)于 **2023-05-20** 公开，落款5月19日，称自5月18日起对其特定非ETF基金采用0.11元。复用 D06 保留的公告字节，按其已提交 SHA256 核验；不移植该基金的正式估值权限。

- **事后变体**明确假设5月19日收盘已采用0.11元，`hindsight=true`。这是使用事后信息的反事实，不是当时可知的投资决策。
- **公开时点约束变体**按上海时区5月20日日终作为保守可得上界，第一可用来源会话为5月22日。在此之前，采用单独声明的0.40人为假设。由于5月22日执行阶段即被阻断，**没有任何已验收会话实际使用该变体的0.11元**；其结果与 A 相等不表示第三方估值已按历史时点成功消费。

所有新假设只在收盘估值阶段入账。5月19日开盘预算沿用5月18日已验收收盘；以后若会话可推进，预算自然消费上一条件收盘，订单数量与现金约束由原执行器自行推导，不复制其他情景的后续订单。[假设、版本与身份](scenario-definitions.json)
