复用既有 `DividendExecutionPlan` / `DividendExecutionLedger` / `dividend_return_accounting` 的职责边界：登记收盘固定资格；除息确认应收；支付转移资产而不重复确认收入；支付日只有日期证据时开盘订单之后入账；期末未付仍为应收。未知税不自动免税，也不进入可用资金。完整覆盖门禁维持不变。

本次最小适配器只提取登记日权益，没有第二套现金生命周期。证据不足时不向既有引擎提交伪造COMPLETE事件计划，不确认实际已收或应收余额，不改变可用现金和持仓。逐日保存原现金、股份、市值、成本、成交净现金流及残差，另列有界累计权益；到账、税、股份调整、总权益及总收益列为空。

两公告对个人/基金股东明确：一年内发放时暂不扣缴，登记日后卖出再按持续持有期计算补扣；不超过1个月20%，超过1个月至1年10%，超过1年暂免。**支付时未扣税不等于税负0。** QFII/沪股通示例10%也不能自动套到未指定账户；其他企业股东可能自行申报。
