# P9-S02：条件情景风险与交易路径归因

**NO LIVE MONEY / PIT_UNVERIFIED / HFQ_UNVERIFIED / FORMAL_ADMISSION_BLOCKED**

本研究复用 [P9-S01B](../p9-s01b/REPORT.md) 的四个真实冻结条件账户，基线为合并 #120 后的 `633308b6b169279a7aaeafdd0ed9987640222b7c`。观察窗口为2023-05-19至06-14共19个来源会话，以05-18共同NAV **929010.2471元**和现金 **1194.2471元**为起点。这里的“真实账户账本”指已实际执行的研究账户输出，不是实盘资金收益。

## 结论

000540的估值敏感性与交易路径依赖同时存在，不能用单一减值解释最终NAV差异。A维持0.40元，B1自05-19按事后0.11元估值，B2自05-22收盘首次按公开时点0.11元估值，C按零元压力估值。四者始终保有133700股000540，不产生停牌成交或权益结算现金。

B1与B2最后的000540账面值相同，最终B2仍比B1少 **3925.841128元**；该差额完全来自不同实际路径下其他证券的毛盈亏差 **−3992.160000元**，以及少支出的手续费 **41.623952元**与滑点 **24.694920元**。因此，这不是终值估值差，也不是已验证策略Alpha。B1的信息时点属于事后反事实，其较高终值不能证明可实现的信息优势。

## 可加总归因

对每个证券、每个会话，毛盈亏为：

`收盘市值 − 前收盘市值 − 当日买入名义额 + 当日卖出名义额`。

它包含实际成交价至收盘及原持仓跨日的行情盈亏；不要求另造无成本执行路径，也不把未知成交机会计入收益。手续费为commission、stamp_duty、transfer_fee、side_fee之和；slippage单列，不能与手续费重复计算。账户净变化等于000540毛盈亏、其他持仓毛盈亏之和减手续费、滑点。

## B1与B2：05-22后的预算与成交分歧

执行器使用当天开盘价标记已有证券，缺失开盘价的持仓使用上一个合格收盘标记，得到`turnover_denominator`，再根据冻结目标权重和最小交易单位产生目标股数；先卖后按rank买入。因000540停牌、开盘价缺失，B1的05-22开盘已携带0.11元，而B2仍携带0.40元。两者开盘价值差恰为 **38773元**，并不意味着B2多了38773元可支用现金。

05-22十个正权重目标股数全部不同，例如000869为2800/2900股、002385为13000/13600股、688088为2270/2368股（B1/B2）。较大的账面预算使B2保留或要求更多目标股份，但停牌仓位不能出售释放现金，排在后面的688088买单受到更强现金约束：B1请求2270、成交2062、拒绝208股；B2请求2368、成交1154、拒绝1214股。B1虽然开盘价值更低，实际买卖总额反而更高：目标较低也使卖出量增加，现金在卖出后按顺序重新分配。因此不能把预算差直接解释成等量买入差。

B2在05-22收盘补记与B1相同的000540估值后，当日NAV反而比B1高 **923.168872元**，后续转为落后。05-29两者仍被603858现金约束（拒绝500/600股）；06-05拒绝200/200股；06-12的600956拒绝700/900股。此时预算已反映此前不同持仓行情及费用，差异持续反馈到目标、卖出、买入和现金。06-12 B2比B1少一笔成交，最终形成上述−3925.841128元差额。05-22一次时点差不能视作仅当日的独立估值冲击。
