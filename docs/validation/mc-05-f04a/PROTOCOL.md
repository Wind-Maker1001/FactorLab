# MC-05-F04A 事前研究方案

研究网格订单有效期怎样改变成交参与、持仓敞口和 Paper 账户损益。所有档位都沿用 F03 的成交、现金、库存和风险规则。

## 固定设计

| 组 | 订单 TTL | 研究用途 |
| --- | ---: | --- |
| A | 48 小时 | 较短有效期 |
| B | 100 小时 | F03 冻结基准 |
| C | 168 小时 | 初始订单覆盖至最后一个撮合观察 |

起点为合成价格锚点，之后每条路径有 168 个小时价格增量。每个模型使用种子 1729、2718、31415 各自的原始 F03 路径编号 0–15。模型为 Jump-down、Regime historical 和 Moving-block bootstrap，批大小仍为 8。全样本为 144 条市场路径，最多 432 个正式账户。每条路径只生成一次，其三个账户的价格指纹必须相同，并与 F03 首档指纹一致。正式重跑全部基准账户，逐路径对照 F03 的既有经济字段。一个配对样本的统计单位是整条价格路径。

[F03 配置](../../../configs/mc05_f03_grid_tail.json)继承 F02 的 NVDAUSDT 快照和模型参数。F04A 沿用同一数据版本、冻结合成起始价格、1,000 USDT 初始现金和零初始库存、几何网格与限额、4 bps 手续费、6 bps 滑点、0.10 合成容量及冻结的突破和重挂规则。资金费为 NOT_SIMULATED。研究在离线 Paper 账户执行，NO LIVE MONEY。

每个账户使用独立 Broker、控制器、存储和临时目录。路径、种子、模型、TTL 与账户身份随结果保存。资源不足或回放异常会中止正式样本。只有通过全量完整性审计的样本才生成配对统计。临时 SQLite 随各账户结束清理。

## 资源与验证

预校准以固定种子 1729 的每模型前三条路径覆盖三档 TTL，最多 8 workers，预算 120 秒。每模型的第一条路径同时做三档串行经济、诊断和身份对照。测量墙钟、全进程树 CPU、RSS、临时文件和预计发布证据，以 1.5 倍成本余量评估整个正式样本。正式墙钟预算为 900 秒，聚合 RSS 上限为 3 GiB，可再生临时文件上限为 128 MiB，机器可读正式结果上限为 4 MiB，盘上留至少 1 GiB。资源拒绝和回放失败记录在研究目录。校准账户用于工程对照，正式统计由正式账户提供。运行时每 100 ms 采样进程树 RSS 和临时文件大小，并在账户结果边界执行限额。达到限额后停止收集，进程池关闭时等待已开始的有限批工作退出。

工程验收要求全部路径指纹及冻结基准经济字段一致、完整配对、FIFO/NAV/库存残差为零，且定向场景覆盖到期撮合与撤单先后、TTL 边界、成交、拒绝、风险退出、串并行一致性与失败关闭。冻结研究证据保留原样。

## 比较指标和统计判据

主要指标为账户是否至少成交一次。对每个模型预先指定 48→100 和 100→168 两个对照，用同一路径的二元转移计算双侧精确 McNemar 检验，以 Holm 法调整六个检验，家族错误率设为 0.05。若至少一个对照通过调整阈值，且至少两个种子出现同方向的非零净转移、其余种子的净转移同方向或为零，则记录 TTL_SENSITIVITY_ESTABLISHED，并把方向结论限定到相应模型和 TTL 对照。其余情形记录 TTL_SENSITIVITY_INCONCLUSIVE。该检验描述冻结生成机制下的模拟参与率。逐种子报告新增和丧失成交、双方成交账户的首成交小时变化，以及订单与持仓轨迹变化。TTL 撤单后首个滑点调整触价是反事实机会诊断。

金融差异以 100 小时为基准，在同一模型、同一路径内计算 48−100 与 168−100 的 NAV、最大回撤、平均持仓市值利用率、成交次数、期末库存和库存 FIFO 净盈亏差。记录均值、中位数、经验 P05/P95 与各种子均值及其范围。区间描述现有样本及种子离散程度。各模型分别报告全体及成交条件组，列明分母，并将超低尾部支持与经验 VaR/CVaR 点估计一同给出。每模型最多 48 条路径，95% 和 99% 尾部的名义支持量分别只有 2.4 和 0.48 条，低于 F03 每尾 20 条的最低支持要求。记录 STATISTICAL_CONVERGENCE_NOT_ESTABLISHED 和 FINANCIAL_NOT_ESTABLISHED。
