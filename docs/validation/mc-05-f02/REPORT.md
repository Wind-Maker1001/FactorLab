## 校准与模型差异

三模型共同使用已核准BINANCE_USDM_PUBLIC_DATA快照，历史观察窗口2026-05-14至2026-08-12，2159条小时简单收益；初始价格204.34，账户初始资本1000 USDT。数据版本及bars身份固定在配置中，正式入口校验身份。模拟起点2026-11-15晚于2026-11-14校准可用时间，不把5月至8月观察时间误称为当时已可研究获取。

**Jump-down**：背景Gaussian log收益均值与样本波动由冻结历史估计；每小时共同Bernoulli事件概率1/168，每次log跳幅log(0.7)，即价格乘0.7，不做jump compensation。频率和幅度是人为压力假设，不是真实市场概率。模型版本、背景参数、来源及事件分布见配置和 `model-calibration.json`。

**Regime historical**：24小时滞后波动及趋势划分low_down/low_up/high_down/high_up；波动阈值只由2026-06-28及以前的观察前缀确定，不根据模拟结果选阈值。状态标签只使用block之前的24条收益；后缀池及相隔24条收益的状态转移由历史估计，重叠样本不是独立转移。实际可用时间仍按采集时间处理，不声称2026-06-28已实时可用。模型校准收据记录阈值可用时间、各状态池、转移支持和矩阵。

**Moving-block bootstrap**：24小时连续历史block均匀有放回抽样，保留块内时序依赖；块连接处打断依赖，不保留无限期波动聚集，未对block长度作结果驱动优化。与Regime使用同一冻结样本，但不按状态分池；与Jump的参数化事件机制不可互换。

历史lag1收益相关-0.037598、平方收益相关0.157534；最差小时收益-4.752711%，最差连续24小时复合收益-7.644529%。更多lag6/24诊断见规划收据。

## 统计与金融解释

每种子16路径的95%有效尾部质量仅0.8、99%仅0.16，条件组更少；CVaR可能完全由单个最差账户决定。经验bootstrap只重采样已观察支持集，无法补足未见尾部。种子之间离散度是描述性差异，不是市场预测区间；本轮没有32/64档序列，不能宣称收敛。零成交是未参与，不是策略成功；低持仓敞口下的小回撤不是风险控制优于满仓基准的证据。Jump库存损失与价格缺口、Regime状态条件下的成交和库存、Bootstrap历史依赖共同构成压力情景证据，不构成外部真实市场验证。
