## 独立账务合同

复用原 `audit_accounting()`核对成交、股数、逐笔/每日现金及交易费用；复用现有分红层的未知税额运算语义。旧严格 `cash_dividend_ledger()`要求完整事件覆盖和支付日期，不能用部分供应商候选强行调用。本版本新增的是多证券、证据可缺失的**同成交路径独立账务适配层**，不是第二个执行器。

- **DIVIDEND_DECLARED**：绑定已核实实施原件及公开时间的声明，不以供应商日期证明预案已实施。
- **DIVIDEND_ENTITLED**：登记日收盘、当日开盘成交完成后的总持股决定资格；除息日买入不取得该次资格，登记日买入后持有至收盘则可以。登记日不在保存会话内时保持UNKNOWN，不能把缺观察解释为零股。
- **DIVIDEND_RECEIVABLE**：在除息日确认已核实每股现金×登记日合格股数的税前应收；实施条款、公开时间或日期未核实则不入账。
- **DIVIDEND_CASH_PAID**：必须同时绑定实际支付日期与对应账户结算证据；计划支付日期和价格跳变都不够。支付借记结算现金、贷记应收，金额相等，不再确认一次收入。非交易日支付保留实际日期，于下一个账面会话反映余额。
- **TAX_UNVERIFIED**：不默认10%、20%或0%；供应商税后字段不替代投资者身份、持股批次/期限及扣缴证据。核实税额与交易费用分开，未知税额不生成可支配净现金。
- **EVENT_UNRESOLVED**：缺失证据、生命周期超出观察、送股/转增/配股/换股/退市结算等未实现类型均保留阻断，不偷偷按纯现金处理。

账务恒等式为：

`限定税前权益 = 原交易现金 + 已核实税前结算现金 + 原持仓市值 + 尚未支付的已核实应收`

`累计已确认股息收入 = 已核实税前结算现金 + 未付应收`

原价损益（扣交易成本）与累计交易成本分别保存。原账本没有现金分红，新增应收只进入独立版本；支付是资产内部转移。**除息后的原始价格下跌仍是价格损益，不额外反推或补记一次分红收入**。不使用HFQ/QFQ价格叠加现金分红。税前结算金额不是未知扣税后的实际可支配净现金；独立适配层也不会拿新增现金重算目标、资金约束或成交。

本次9条候选均为EVENT_UNRESOLVED，因而已核实分红记账分录为0。这个0仅指**已核实并过账的子账**；实际应收总额、实际收到总额、分红税额和公司行为敏感性收益均为null，不以0冒充没有股息。
