   - 价格敏感性测算假设在首次突破时按收盘价 `132.36000` 立即全额平仓且无费用，情景净收益为 `0.11080000 USDT`。它与实际净收益的差额为 `-0.07643384 USDT`（实际减假设）。成交概率、排队和滑点均未纳入该测算。
   - 在价格及仓位固定、资金费延续最后 3 小时均值 `0.01441651 USDT/h` 的情景中，再持有约 `2.38 小时` 会耗尽实际剩余净利 `0.03436616 USDT`。
