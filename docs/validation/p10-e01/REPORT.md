## BigQuant：当前定义充足，批次适用仍未闭合

取得以下完整 HTTP 响应原件，阅读正文而非搜索摘要；保留必要原文摘录于 [official-source-excerpts.txt](official-source-excerpts.txt)，完整响应的获取哈希、大小、方法和 UTC 完成时间见 [证据矩阵](supplier-evidence-matrix.json)。原件完整响应位于本次临时获取目录，不作为商业行情附件。

- [官方未复权字典](https://v6.bigquant.com/data/datasources/cn_stock_real_bar1d)：HTTP 200。明确“未复权价格是交易所公布的原始成交价格”；OHLC 是未复权日线；`volume` 为股、`amount` 为元，均为当日累计值。停牌/无成交保留行，OHLC/amount 空、量等为零，前收和限价保留；无涨跌幅限制限价是占位值，不是真实价格。
- [官方后复权字典](https://bigquant.com/data/datasources/cn_stock_bar1d)：HTTP 200。明确后复权价 = 原价 × 累计后复权因子，量额不复权。这支持区分两张表，不支持给调整链发证。
- 原价页面服务端元数据存在 `version="official"`、`created_at="2023-07-01T10:20:28.716784+08:00"`、`updated_at="2026-11-11T20:35:11.528220+08:00"`。没有随附语义修订 ID、生效区间、导出快照或收据引用。创建时间不是行情起始可得时间，更新时间不是历史适用日期，`official` 标签不能绑定 13 个批次成员。
- [v6 迁移指南](https://bigquant.com/wiki/doc/invzMsVhXH)及[迁移问答](https://bigquant.com/wiki/doc/tCZKYbtFwU)：HTTP 200，为官方站点承载、用户账号署名的文档，**没有据此认定作者是供应商授权维护者**。指南要求保留旧环境同输入查询结果；问答对同查询不同结果要求检查数据源、字段类型、空值等并比较键和值。这是迁移排查说明，不是数据集历史定义或本批次无修订保证。

通用 DAI 猜测入口 `/wiki/doc/dai` 返回 HTTP 404，不据此说 DAI 文档不存在。三次定向 WebSearch 没有返回结果，不据此说没有版本记录。WebFetch 因域名安全验证失败未取得 HTTP 状态；实际正文通过普通未认证 curl 成功取得，没有绕过供应商访问权限。以上 UTC 由获取命令原样记录为 2026-11-11，任务会话日期为 2026-11-12；不伪造精确访问时间。

### 尚需哪份证据

缺少的是 **导出批次适用确认，以及未明示的经济细节**，不是完全没有历史价格字段说明。必须由可识别供应商来源确认：当前或另附定义适用于附件 2026-11-07 快照；OHLC 为人民币元/股的未复权真实成交观察；停牌/无成交和自动填充规则；历史追溯修订规则；如曾变化，说明快照生效区间和受影响观察日期。对前收、限价及量额应逐字段答复，不从 OHLC 资格传递。

**不机械要求 2023 年网页与今天同文**：2023—2024 年是行情观察期，2026-11-07 才是本次导出。可接受版本化文档或等价的正式批次确认，无需强求供应商采用特定版本编号体系。即使没有历史首次分发时间，仍可评估明确范围的回顾性原价资格；提供历史 cutoff 的 PIT 使用则继续因 `available_at` 未知而受阻。

[中英文询证正文](supplier-inquiry.md)和[最小身份附件](batch-identity-manifest.json)可直接交由账户持有人提交。**REQUEST_PREPARED_NOT_SENT**：没有实际发送、工单或供应商回复，不将询证准备完成解释为确认。
