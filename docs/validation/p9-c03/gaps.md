# 税务、修订链与完整性缺口

## 税务

九份2023实施公告含当期税务说明，但模型名称不能证明投资者类型。财税〔2012〕85号、财税〔2015〕101号等在公告中的引用支持区分持有期与递延扣缴规则，不支持选定某个账户税率。QFII、沪深股通、企业和个人也不是可互换资格。

## 更正、取消和延期

本轮从巨潮按精确股票代码＋披露机构ID，取得2023-05-01至2023-08-15全部分页公告索引，共280条标题记录。初始关键词检索有其他证券命中、缺页及漏实施标题，故不作为完整发行人索引；最终结果使用精确发行人过滤重新取得。原查询记录保留私有，最终索引标题、页摘要及实施原件公开保留。

该限定索引没有出现带“权益分派／分红派息”且带“更正／取消／延期／调整”的标题。它只证明限定窗口和标题条件下没有命中，不能证明正文无修订或窗口外无后续更正。公告说明实施与股东大会方案一致，仅用于核对该份实施方案，不等于后续修订链完整。

## 正持仓区间完整性

原P9-C02保存513个连续正持仓区间、89只证券，区间清单身份见 event-completeness.json。继承P9-C02两类事件四个年度分片的原读取收据及DQ-03精确交集，核对DQ-C01既有表元数据，相关行保存在 existing-source-coverage.csv。已用分红表提供现金与送转候选，配股表提供配股候选；这两类记录不覆盖所有换股、退市结算、取消、跨期应收及其他权益事件。DQ-C01全字段内容扫描也不构成持仓区间经济事件完整性合同。

九发行人的公告索引只覆盖固定补证窗口，并非89只证券的全持仓区间索引；故保持 `EVENT_COMPLETENESS_UNKNOWN`。未新增读取供应商分片，不因没有命中配股就断言没有其他公司行为。

## 验收状态

`W01_EVIDENCE_ACCEPTED` 需要其声称的全部资格均有完整证据；`W01_PARTIAL` 表示已获得可独立复核的实施、支付安排和账户权益，但仍有上述缺口；`W01_BLOCKED` 用于没有足够证据支持目标账务的情况。本轮为W01_PARTIAL，九事件各自已取得的有限资格不因整体PARTIAL被抹掉，也不因九份公告齐全被扩大到实际到账／税后／全事件完整性。
