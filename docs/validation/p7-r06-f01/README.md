# P7-R06-F01：资金费调整后的等敞口基准比较

**NO LIVE MONEY · EXPLORATORY_RESEARCH · INCONCLUSIVE**

## 结论

双方计入历史资金费后，R06 的结论不变：等比网格在此窗口仍盈利，且优于相近平均敞口的固定持有，但仍落后于依赖网格历史信号的滞后一小时动态对照。资金费并未改变排名，反而将动态对照的领先幅度扩大 **0.006476649 USDT**。因此没有证据将 R06 的 INCONCLUSIVE 升级为正经济优势结论。

INCONCLUSIVE 针对“等比网格相对可比基准具有不依赖基准方法的正经济优势”这一问题；不是说本窗固定持有比较没有明确结果，也不是跨窗口统计结论。动态对照是 **EX_ANTE_GRID_DEPENDENT_LAGGED**，并非独立 Buy & Hold 或独立 alpha 策略。

动态领先主要在叠加资金费之前就已存在，不是资金费创造的。R06 原指标中，基础网格/动态交易成本分别 0.355002966480 / 0.354850861840，差额只有 0.000152104640；原领先中的剩余 **0.436000000000 USDT** 来自扣交易成本之前的持仓价格路径与执行安排。压力下交易成本差为 0.000302417600，剩余 **0.435000000000 USDT**。一小时滞后及合法成交约束改变实际持仓时段，在这个窗口捕获了略有利的价格路径；不能把此会计分解解释为无需网格信号的可执行独立收益。

回答六项研究问题：

1. **网格资金费后仍胜相近固定持有：是。** 两档分别领先 5.78–6.22 USDT，且自身仍盈利。
2. **与动态对照排名是否改变：否。** 两档动态仍第一、网格第二。
3. **动态是否承担更多资金费：否。** 动态比网格少付 0.006476649 USDT（约为网格净负担的 0.97%）。平均敞口相似不保证结算瞬间持仓相同。
4. **动态为何仍领先：** 主要是原有价格路径/执行安排优势，成本差及资金费差只小幅加大领先。
5. **网格是否因资金费反超：没有。** 不存在可归因于费用负担差异的反超。
6. **是否升级 R06：否，维持 INCONCLUSIVE。** 固定持有与动态对照仍给出不同方向的收益差。单一标的、单一窗口不能证明稳定超额收益。

## 结算实现与证据

直接复用 R05 `grid_funding.py` 的 `settlements`、`cashflow`、`drawdown`，将其既有事件持仓结算和小时 NAV 叠加抽为 `position_settlements`、`account_overlay`，供原 R05 账户入口及本研究共同调用，没有第二套结算算法。

使用已取得的 **279 个事件：278 Regular、1 Special**，均有历史 markPrice。逐事件现金流为 `−结算前实际带符号数量 × markPrice × fundingRate`。正值收款，负值付款；多空和正负费率均保留。按实际返回事件结算，不假定固定八小时时刻。毫秒时间由 epoch 整数换算；同时间不同类型分别计费，重复的同时间同类型事件拒绝。

R06 `fills.csv` 的 `execution_date` 实为小时桶起点，`simulate` 在该小时完成时按 close 执行。因此成交事件时间归一为 **桶起点 + 1 小时 − 1 微秒**，不是按标签在桶初提前持仓。每个对照只累计自身实际 BUY/SELL 数量；不复制原网格仓位，不重新执行动态目标。零仓位为零费用。主口径只纳入严格早于结算时刻的成交，同刻以先结算后成交处理，并另算成交优先的替代结果；本窗所有账户先后差均为零。

小时研究 NAV = 保存的小时权益 + 截至桶末累计资金费；期末包含右开窗口内全部结算。最大回撤从初始 1000 开始按这些小时观测计算，不声称盘中最大回撤。网格不重算：仅读取 R05 已有 `summary.csv`、`settlements.csv`、`nav.csv`，核对其事件集合与本次原始资金费完全一致、现金流总和、逐小时 NAV 调整关系和回撤。其基础/压力调整收益分别精确对接 **4.282893700316257230 / 3.962952834476257230**。四类账户原净收益均与 R06 已有 metrics 对接（容差 1e−9 USDT，仅用于原浮点导出的末位）。

固定 0.12/0.13 是 R06 已有合法执行账户，以已实现平均敞口选作相邻比较节点属于事后比较选择，不改变其实际建仓规则。精确路径归因不是第五个可执行账户，不纳入排名。

## 额外不利资金费敏感性

固定原成交与持仓不变：

- 网格基础/压力可再承受 4.282893700316 / 3.962952834476 USDT 的额外费用至零收益；动态为 4.725522453956 / 4.404731901076。固定持有已经亏损。
- 若仅给动态增加额外不利费用，基础 **0.442628753640**、压力 **0.441779066600** USDT 可使它与网格打平；再多才会网格反超。双方增加相同的 USDT 费用不会改变收益差。
- 若仅给网格增加费用，抹去其相对固定 0.12/0.13 的领先需基础 6.069182496590 / 6.218039896279、压力 5.776653753278 / 5.927795496511 USDT；这是相对排名边界，不是仍保持盈利的预算。
- 同时将双方本窗实际资金费路径乘共同非负倍数 λ，网格减动态的差为基础 `−0.436152104640 − 0.006476649 λ`，压力 `−0.435302417600 − 0.006476649 λ`。**λ ≥ 0 不会令网格反超**。相对固定 0.12/0.13 打平倍数为基础约 60.3775 / 113.7695、压力约 57.5156 / 108.5057。CSV 空值表示不存在非负打平倍数或比较自身，不表示零。

原始现金流倍数不是未来费率预测，也不是给缺失事件编造费用。`break_even_observed_funding_multiplier` 沿用 R05 的代数盈亏平衡值；固定持有的负倍数不属于额外不利资金费情景。

## 权益与研究边界

这是**事后资金费归因叠加**。原 Paper/FIFO 权威账本、成交、现金约束、下单量、风险退出及未成交订单均未修改。资金费若在真实账户改变可用资金，可能改变后续下单、成交或退出；本研究固定原路径，未进行完整资金费驱动反事实交易重放。资金费后研究 NAV 不是改写后的原权威 NAV。

沿用 R04B/R06 的 PIT_UNVERIFIED、HFQ_UNVERIFIED、LISTING_UNVERIFIED 边界及小时 close/合成滑点执行模型。公开 API 返回事件全部用于本次归因，但没有独立交易所应结算事件清单。只有一个历史窗口，未增加样本、筛选窗口或优化参数。
