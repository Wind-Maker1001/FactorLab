# Walk-Forward 样本窗口可行性

**CANDIDATE_STRUCTURALLY_FEASIBLE / FORMAL_ADMISSION_BLOCKED / NO LIVE MONEY**

本轮只衡量数据和标签端点，不拟合模型、不生成目标收益、预测或策略回报。两套配置由时间长度决定，不按收益挑窗。逐折结果见 [walk-forward-windows.csv](walk-forward-windows.csv)。

## 时间与有效样本合同

使用 `ExpandingWalkForwardSplitter`，固定训练起点，按3个日历月扩展；Validation/Test各3个月，窗口半开。输入为原始历史成员日，不先删除缺值证券或整日；会话取实际读取的BigQuant CN日历，不由工作日推断。末端完整性判断沿用现有splitter，最终测试窗名义终点2026-09-13，实际末会话2026-09-11。

- purge=5会话，embargo=5会话；标签沿用 `forward_return.py` 的**时间合同**：t收盘信号、t+1开盘进入、t+6开盘退出，对应5持有日。这里只检查正有限开盘端点与基准端点日期存在，不计算任何比值或收益。
- Train的exit必须严格早于Validation首信号，Validation的exit必须严格早于Test首信号。由于t+6，现有5日间隔外还各删1个信号日，即每折额外500成员日；名义Train和Validation分别总删6日/3,000成员日。不能只设purge=5便声称标签已成熟。
- 预热从2021-01-13开始，共享1,388会话网格的起段先于研究开始；全部定义最大prior-session lookback=60，原14最短1，64候选最短4。证券上市过晚、内部缺值或终止行情仍会损失样本，不以“有八个月预热”宣称每只证券均已成熟。
- 历史Test端点按本次观察截止2026-10-11检查；没有把尾部价格传给未来方向的因子公式。数值隔离则是全诊断范围事后阻塞，不能当成as-of训练股票池。未检查持有期可执行交易、完整公司行为或因果复权，故端点存在不等于合格金融标签。
- `all14/all64/all78_finite`分别是各组全部因子有限；`*_with_label_endpoints`再要求端点；`*_structurally_eligible`再要求默认结构筛选代理。原分母、逐步剔除及重叠均保留，不能把各缺失原因计数直接相加。

## 最小候选：12/3/3月

第一折为2021-09-13起18个日历月，后续3月步进，可提供15折。第一折：

|阶段（半开）|名义成员日|边界审计后日数/成员日|全部78因子+端点+结构代理|每日共同样本下限|
|---|---:|---:|---:|---:|
|Train：2021-09-13—2022-09-13|120,500|235 / 117,500|115,252|485|
|Validation：2022-09-13—2022-12-13|30,000|54 / 27,000|26,628|490|
|Test：2022-12-13—2023-03-13|29,000|58 / 29,000|28,401|489|

Train保留样本相对边界审计后分母为98.0868%，Validation为98.6222%，Test为97.9345%。按数据规模，这已足以作为后续非收益接口实验的最小候选；并不证明12个月具备充分市场周期或统计功效。

|---|---:|---:|---:|---:|

|Validation：2023-09-13—2023-12-13|29,500|53 / 26,500|26,378|497|
|Test：2023-12-13—2024-03-13|29,000|58 / 29,000|28,694|494|

若下一阶段希望复用Runner的默认训练长度，建议用这套作为主要结构候选，以12/3/3作为更短的数据接口基线；两者不是两个独立测试证据池。最末折两套收敛为相同边界：Train至2026-03-13、Validation至2026-06-13、Test至2026-09-13；共同样本分别532,481、27,489、31,740，实际信号日1,079、56、64。

26折的所有Train/Validation/Test日横截面最低共同样本为 **485/500=97%**，低于既有minimum_cross_section=20的日期0。Train跨多次调样而拥有超过500个不同代码是正常现象，不表示某一天成分超过500。重叠Train或重复Test配置的成员日不能加总为独立样本总数。

## 因子覆盖与可解释边界

[factors.csv](factors.csv)包含不可变依赖、版本、定义哈希、lookback与实际计算统计：

|组|定义数|逐因子有限成员日范围|有限覆盖范围|实际∞|有≥20值的日横截面常数/低变化|
|---|---:|---:|---:|---:|---:|
|原始14|14|598,112—603,687|98.7799%—99.7006%|0|0 / 0|
|P3-11候选|64|598,112—603,687|98.7799%—99.7006%|0|0 / 0|

本轮14组与64组的共同掩码恰好同为598,112，因而78交集也相同；这是实际结果，不是把同一覆盖率硬复制到每个定义。各因子矩阵保留不同的有限/NaN数量。报告中的NaN含缺行情、预热不足、公式分母规则与整证券阻塞，不能全部称为“供应商原字段缺失”。

常数的证券内判定为至少2个成员观察且min=max；证券内低变化为样本标准差≤1e-12；日横截面低变化为有限值≥20且max-min≤1e-12。此次证券内常数/低变化均0。阈值只是绝对数值诊断，不证明信息量、经济独立性或可预测性；没有执行相关性去冗余或Train-only因子选择。

当前原价与调整价候选分开读取；Registry V2的HFQ价格类别只是公式需要的类别。现有 `cn_stock_bar1d` 的方法、绝对锚点和历史修订未认证，所以 **78个有数值输出不等于78个金融证据合格因子**。TURN水平因子还依赖未闭合的换手单位和股本口径；amount/volume的单位、停牌表示同样需要供应商合同。

3. 若从2016-11-07即要求最长60日因子与120日上市年龄，现有BQ导出起点之前的预热合同不足；可以在取到更早必要预热后保留起点，或将第一研究信号推迟到确有足够历史的会话，不能补零。
4. 历史合同与样本核验成立后，仍复用24/3/3与t+1/t+6边界规则；这只是条件配置，本轮不报告未经计算的十年折数/有效样本数。
