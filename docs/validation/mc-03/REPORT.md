### 研究问题的回答

- **高波动持续不必然增加本次 Grid 风险。** 历史状态模型MDD尾部高于GBM/MBB，但高波动持续压力相对历史状态模型的VaR/CVaR和回撤反而更低。状态标签条件化的是历史区块起点，不是人为放大每步波动；Grid触发、暂停、实际库存与有限样本共同决定账户损失，不能据此推导高波动更安全。
- **跳跌可以把已有库存变为显著残余损失。** 下跳组最差期末残余损失24.61125 USDT，期末库存至多0.20；相同参数化背景无跳跃组最差残余损失3.66274。下跳组每步事件概率1/168仅为压力假设，多次事件允许发生。并非每次跳跌都会增加库存：直接越界可触发pause或阻断入场。
- **确定性持续下跌揭示更大的库存尾险，但随机下降标签不等于单调下跌。** 原连续下跌40%路径期末NAV970.71806、库存0.50、残余损失29.28194；下跌后反弹不足路径NAV989.0681、库存0.50、残余损失10.93193。随机下降持续组风险较低，其抽取区块仍可上涨或反转；不以该标签声称已模拟所有连续趋势风险。
- **切换假设会改变风险统计，但方向不是预定的。** 三种状态矩阵的VaR、CVaR、MDD均不同，初始状态分布相同。小样本下不对差值作显著性或真实市场优劣判断。
- **场景更丰富且可解释。** 参数化跳跃允许价格变化超出单个历史区块的形态；高波动/下降状态持续可在保留联合区块顺序的同时改变区块拼接概率。解释来自冻结阈值、可查转移矩阵和显式跳幅，不来自未来价格预测。

六类确定性路径账户结果与R10一致；其中横盘后直接跳跌没有成交，不能解释为跳跌无风险。所有路径权益归因对账残差绝对值不超过 `1e-24`。
