# P10-D01：CNRDS 历史重复键根因调查与安全处置

**PARTIAL — NO LIVE MONEY / PIT_UNVERIFIED / HFQ_UNVERIFIED / FORMAL_ADMISSION_BLOCKED**

## 结论及证据层次

2021 年 1 月 84,514 个歧义键全部复现，涉及 169,028 条原生记录。三个一月份检查点共有 169,448 行、84,934 个证券日期键，其中 420 个键唯一。对这些 169,448 行逐一回查 ZIP 原件的工作表、物理行和完整原生字段，全部一致。三个工作簿成员及字段说明的 SHA256 均与 PR #85 的已合并清单一致。因此，重复已经存在于归档工作簿中，**不是提取器把同一物理行重复拼接产生**。

84,513 个重复键位于同一工作簿、同一工作表的相邻物理行；仅 1 个键跨 `_1.xlsx` 与 `_2.xlsx`。全部 84,514 组均表现为一条 `Adclsprc` 非空、另一条为空；这是原件结构观察，不是认定非空版本更正确的依据。不同文件都覆盖 2021-01-04—2021-01-29，但日期范围重叠不能证明重复导出或供应商版本优先关系。本次没有将任何键认定为已证实的 `OVERLAPPING_EXPORT`。

所有重复组都有完整原生字段差异，没有一组满足完全重复归一条件。可复现的分类如下，分类互斥：

|分类|键数|证据及处置|
|---|---:|---|
|EXACT_DUPLICATE|0|全部原生字段、空值状态及文本必须相同|
|OVERLAPPING_EXPORT|0|没有权威导出版本/优先级证据，不凭跨文件推定|
|CONFLICTING_VALUES|79,214|供应商代码、名称、日期相同，但其他原生字段不同；全部隔离|
|IDENTITY_AMBIGUITY|5,300|同代码同日期但 `Coname` 不同；全部隔离，不推断为不同发行人|
|UNRESOLVED|0|逐键内容分类已完成；供应商业务根因仍未闭合|
|合计|84,514|可安全归一 0，继续隔离 84,514|

`UNRESOLVED=0` 不表示根因调查完整：这里表示没有无法进行**内容分类**的键。记录来自何种导出构建、版本或统计口径，仍未获得供应商权威说明，整体结论因此为 PARTIAL。

## 差异是什么

全部 84,514 组供应商 `Scode` 相同；其中 5,300 组名称不同。这支持按供应商原键定位，但不认证稳定历史发行人身份。

60,914 个键仅在 `Adclsprc`、`Adclsprcp`、`Adret` 的子集上存在差异。其余差异还涉及流通股本、总股本、市值、换手率、收益率、成交额以及少量 OHLC 等，完整字段组合及逐字段键数见 `impact-summary.json`。不能把这些记录整体描述为“只是复权字段空值不同”。

79,214 是排除名称歧义后的**原生字段冲突分类数**，不等同于两条非空数值不相等的键数。按原始十进制精确比较、排除仅空值/非空和仅格式差异后，**19,687 个键存在实际非空数值冲突**；其中 1,387 个同时属于身份歧义分类，不能与前述分类直接相加。84,514 个键中有 82,717 个原价六字段文本完全一致、1,797 个不完全一致；原价六字段一致也不授权合并其他经济内容。

另有 `_1` / `_2` 跨成员键 1 个。物理行范围是定位包络，并不意味着范围内所有行都是一月份。逐组成员 SHA、工作表、行号、全部候选及不选择依据保存在私有 `candidate-lineage.jsonl`。公开 `evidence_id` 是证券日期与全部坐标的 SHA256，用于与私有证据关联；公开 CSV 不发布证券日期或行情值，不能从公开交付重构供应商行情。

`source-overlap.csv` 按来源成员组合聚合重复键；每个成员的一月份日期范围、行数和物理行范围亦记录于 `input-manifest.json`。

## 最小处置及研究影响

本次只增加只读审计器，不修改现有比较器、供应商原始文件、DataHub、冻结研究输入、模型输入或历史绩效。完整字段一致时可形成保留全部原始行身份的等价类，不从文件顺序选择代表；本次没有符合条件的组。其他组保留全部候选并继续排除。没有默认 `keep=first/last`，不使用未来行情，不用其他供应商替换冲突。

因此，**原三源交集可增加有效键 0 个**，原审计排除规则继续适用。即使仅投影原价六字段，82,717 个一致观察也不等于完成全记录安全归一或认证了供应商身份、历史可得性。

既有 CSI500 成员日研究窗口为 2021-09-13—2026-09-11（见已合并 `tri_source_market_audit.py` 的成员日过滤），与此次 2021 年 1 月没有交集：直接受影响成员日 0，原 CSI500 三源交集仍为 578,592。固定 24 证券 2015—2018 及 601857.SH 2017—2018 窗口也不受此次时间范围影响。

对于包含 2021 年 1 月的其他回测或模型，若使用原审计隔离后的输入，覆盖不变；若绕过隔离直接使用原始 CNRDS 数据，重复观测会使键连接扩增，或使不显式仲裁的选行行为依赖输入排列。涉及复权、市值、流通股本、换手率和原价等特征时还可能改变经济含义。这里不据此推算绩效差异，也不改写历史绩效。
