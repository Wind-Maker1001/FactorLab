> **安全边界与声明**：`NO LIVE MONEY` · 离线受控历史与模拟研究，不操作 Azure 生产实例，不自动修改生产策略，不将历史回测收益包装为真实模拟或实盘盈利。所有已用窗口（含 `2023–2026` 主窗口、`twenty` 二十年窗口与 `2001–2006` 历史挑战窗口）均属于**历史复用或重复研究窗口（`HISTORICAL_REUSE_PSEUDO_OOS`）**，真正未消费的新样本外窗口尚不足，金融准入维持 **`FORMAL_ADMISSION_BLOCKED`**。

## 1. 核心金融结论摘要

1. **原始交付包业绩真实可复现，但高度依赖单只标的 `SNDK` 与选股池幸存者偏差**：
   - 在 `2023-01-03` 至 `2026-11-23` 主窗口（`target/normal`，单边 `10 bps`）下，`V179` 净收益 `+186.98%`（CAGR `31.25%`，Sharpe `1.78`）、`V182` 净收益 `+177.19%`（CAGR `30.08%`，Sharpe `1.75`）、`V69` 净收益 `+38.83%`（CAGR `8.83%`，Sharpe `1.84`），同期标普 500 总回报（`^SP500TR`）为 `+98.78%`（CAGR `19.39%`，Sharpe `1.24`）。
   - **集中度冲击（关键风险）**：主窗口内仅 `SNDK`（2025-02-24 上市）一只标的就贡献了 `V179` 总净损益的 **`68.9%`（\$386,302 / \$560,944）**、`V182` 的 **`65.3%`（\$347,002 / \$531,571）** 与 `V69` 的 **`56.1%`（\$65,311 / \$116,497）**。剔除 `SNDK` 后，`V179` 主窗口净收益骤降 `-118.4 pp` 至 `+68.62%`（CAGR `14.43%`，Sharpe `1.17`），`V182` 骤降至 `+70.05%`（CAGR `14.68%`，Sharpe `1.18`），**两者均跑输同期标普 500 总回报（`+98.78%`，Sharpe `1.24`）及 70% QQQ 再平衡对照（`+93.22%`，Sharpe `1.23`）**。
   - **二十年窗口同样受单一标的与幸存者支配**：在 `2006-11-20` 至 `2026-11-20` 二十年研究（`twenty`）中，仅存续最后 440 个交易日（占比 `8.7%`）的 `SNDK` 仍贡献了 `V179` 二十年总美元净利的 **`51.6%`（\$1,158,688 / \$2,244,601）**。剔除 `SNDK` 后，`V179` 二十年累计净收益由 `+748.20%`（CAGR `11.30%`）跌至 **`+397.09%`（CAGR `8.36%`）**，低于标普 500 总回报（`+620.36%`，CAGR `10.39%`）与 70% QQQ（`+675.28%`，CAGR `10.80%`）。同时，剔除 `AAPL` 使二十年收益下降 `-395.5 pp`，说明这组由人工事后指定的 8 标的池存在显著的幸存者与主题选择偏差。
   - 相比之下，`TQQQ` 并非主要异常来源：因原始策略层对 `TQQQ` 施加了 `1/3` 权重缩放及 `QQQ > MA63` 门控，`TQQQ` 仅占主窗口/二十年净损益的 `6.5%–10.6%`，剔除 `TQQQ` 后 `V179` 主窗口与二十年 Sharpe 分别仅微降 `1.78 → 1.76` 和 `0.83 → 0.81`。

2. **真实的经济机制优势在于低 Beta 危机防御，但伴随横盘锯齿损耗与高换手成本敏感性**：
   - 跨 2001–2026 年三大系统性熊市（`2001–2002` 互联网泡沫标普 `-31.4%`、`2008–2009` 金融危机标普 `-35.0%`、`2022` 加息熊市标普 `-18.1%`），三策略凭借 28 日趋势波动带退出、`QQQ > MA63` 门控和低平均仓位（`V69 ~15–19%`、`V179/V182 ~52–65%`）显著压低了危机最大回撤（金融危机期间 `V69 +0.5% / DD -8.1%`、`V179 +4.3% / DD -20.0%`、`V182 +2.0% / DD -21.6%`）。
   - 然而，在 20 年中占比 `44%`（`2,208 / 5,032` 日）的**横盘震荡体制（63 日标普收益 ∈ `[-5%, +5%]`）**下，三策略年化均值为负（`V69 -0.7%`、`V179 -2.7%`、`V182 -2.9%`）；在 `2013–2019` 低波慢牛（标普 `+161.7%`）下显著跑输基准（`V179 +69.9%`、`V69 +15.3%`）。
   - **交易成本与日内滑点高度敏感**：二十年窗口内，`V179` 常规费用（`10 bps`）下 CAGR 为 `11.30%`（费用 \$190,910）；三倍费用（`30 bps`）下 CAGR 降至 `8.56%`（费用 \$414,203）；五倍费用（`50 bps`）下 CAGR 降至 `5.88%`（Sharpe `0.47`）；若遭遇日内不利成交（买在 `(open+high)/2`、卖在 `(open+low)/2`），二十年 CAGR 暴跌至 **`3.73%`**（MaxDD `-33.47%`，Sharpe `0.33`）。

3. **版本演进与过拟合风险检验：`V182` 并未优于 `V179`，多重检验显著削弱统计把握**：
   - `V182`（编号最新）在 `target/normal`（`+177.19%` vs `+186.98%`）、`dev_crisis`（`+37.71%` vs `+40.98%`）与 `twenty/normal`（`+707.26%` vs `+748.20%`）均略弱于开发入选版 `V179`，且在 `twenty` 上与简单静态 `50/50` 混合（CAGR `10.96%`，Sharpe `0.81`）几乎无实质差别（`V182` CAGR `11.03%`，Sharpe `0.81`）。
   - 计入 `v48 → v182` 历史迭代家族的多重检验（`N = 182` 试验次数）后，Bailey & López de Prado **紧缩夏普比率（DSR）**显示：剔除 `SNDK` 后，主窗口 `V179/V182/V69` 的 DSR 概率仅为 **`0.33 / 0.34 / 0.38`**，二十年窗口仅为 **`0.59 / 0.58 / 0.52`**，历史挑战窗口 `2001–2006` 仅为 **`0.15`**——在严格多重检验校正下无法排除数据挖掘选择偏差。
