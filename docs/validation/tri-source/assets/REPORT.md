- `cn_stock_name_change`：**18,422 行、5,314 个代码、11 个分片**，候选键 `(instrument, start_date)` 重复超额与冲突键均为 0，四字段缺值均为 0。名称起始日期为 2005-01-04—2026-11-05；结束日期为 2016-11-07—2026-11-05。区间起始时间早于导出查询窗不据此判错。

名称历史不是证券代码迁移表，更不是稳定证券 ID。对同一证券跨区间的多条名称记录，不能用单列 `instrument` 作主键后误报重复。本轮没有认证名称区间连续性、跨证券代码承继或撤销替换链。

### CNRDS 原生日行情样本

输入为 `CNSP_个股日回报率_ALL.zip` 中 `2018/个股日回报率-2018_1.xlsx`，读取首张表的英文表头和中文说明行，再检查 **5,000 条数据记录、21 个裸代码**。观察日期为 2018-01-02—2018-12-28；这不是全表或任一指定证券的完整年度覆盖。

- 候选键 `(Scode, Trddt)` 重复超额 0、冲突键 0、空键 0；日期解析异常、代码格式异常、周末观察均为 0。
- 所有原生列的空值计数均为 0，但 **Dtrdvol、Dtrdamt、Dtnor 各有 368 个非数值非空单元格**。因此“空值为零”不能解读为成交量、金额、换手率完整可计算。计数是按列的，不能相加称为 1,104 个异常证券日。
- 可解析价格非正及 OHLC 顺序异常均为 0，可解析成交量/金额负值均为 0。数值探测没有修改字符串、填零或替换原值；非数值单元格的供应商缺失/状态语义仍待合同。
- 样本未见替换字符编码异常。工作簿价格等数值以字符串单元格提供；类型统计保留 object，不将分析时的数值探测当作原生类型。
- 实读年度字段说明给出了原价、前/复权价、成交量与金额等定义及元/股等单位文字；没有据此推定复权算法、精度、有效期、历史首次可得或国际币种代码合同。

## 4. 三源覆盖矩阵如何使用

[coverage.csv](coverage.csv)区分实际有界记录、旧记录证据、仅表/文件存在和证据不足。数据域由名称规则辅助归类，不是供应商认证的经济含义；文档文件不单独当作数据记录证据。

- **三源有记录证据**：行情域。CSMAR 依旧原生扫描，BigQuant 依旧有界行情读取，CNRDS 依本次前缀样本。三者不代表同一证券/日期全集，更不证明字段可比。
- **两源有记录证据**：公司行为和身份域，均是 CSMAR / BigQuant；CNRDS 有相关资产但内容未读。
- **单源有记录证据**：其他域中的部分 CSMAR catalog 内容，具体须查清单，不能外推该域全集。
- 财务、指数、行业、状态、日历等域存在资产或其他已引用研究证据，但矩阵不把仅 schema、收据或目录观察转成该域全量记录覆盖认证。

本次没有设定统一证券日目标集合，所以 `no_target_records=NOT_EVALUATED_WITHOUT_FIXED_TARGET`，没有把“没有读取目标”伪装为“表中没有目标记录”。字段可比性保留 `INSUFFICIENT_EVIDENCE`；BigQuant 的价格、量额单位和精度合同尤其缺失。目标无记录和语义不可比必须在有明确查询对象、实际读取及独立字段合同后分别判断。

## 5. 历史身份与 PIT

三源共同缺少可认证的稳定证券 ID、完整历史代码转换、供应商首次分发、修订/替换/撤销链及字段字典有效期。BigQuant 的历史名称和快照上市/退市字段只是新增观察，不填补这些缺口。

|时间|本次记录原则|
|---|---|
|`observed_at`|审计器本轮观察 UTC 时间|
|`published_at`|首次公开时间；没有独立证据保持 UNKNOWN|
|`available_at`|供应商首次可得时间；保持 UNKNOWN|
|`effective_at`|仅在字段合同足以支持时使用事件生效时间，不把所有 date 统一解释成交易日|
|`exported_at`|保留 BigQuant 收据导出时间，不替代历史 available_at|
|`collected_at`|本地获取时间；没有来源收据保持 UNKNOWN，不使用 mtime 填补|

文件哈希绑定内容，不认证供应商身份、独立上游或历史真实性。2026 年导出载荷没有被改称历史 PIT 快照。
