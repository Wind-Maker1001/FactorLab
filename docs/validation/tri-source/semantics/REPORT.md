## 调整因子：有差异，尚无可互换合同

[调整合同表](adjustment-contracts.csv)分别记录原价、再投资可比价、单事件和累计因子。CSMAR Adjprcwd的现金再投资可比语义不等于执行价格，也不自动等于BigQuant的price_gap链。BigQuant日行情adjust_factor与事件因子表同名字段不能直接互换；CNRDS区分原价、复权及前复权日收盘价，产品引用CRSP仍不足以给出绝对后复权算法。

既有四组BigQuant−CSMAR向前因子差依次为−0.0002573471502591、−0.000092310087173、+0.0000997466307278、−0.000133642857143；向后因子也全部不同。此处SEMANTIC_CONFLICT表示不能作为相同定义的替代输入，**不是已经认证某源数值错误**。P3-D03的现金分位舍入候选只是待核对解释，不在本轮拟合或认证。

算法、价格基准、绝对锚点及日期、前置事件范围、内部精度、舍入位置、复合行为顺序、历史修订及版本合同未闭合，因此不执行“已定义关系”的强等式认证。不能将单日因子当累计因子，不能以四个窗口事件重建上市以来绝对锚点，也不能用价格比值残差小授予HFQ。当前前复权会受窗口后事件及终点影响；后复权名称也不保证不受晚到修订影响。三源历史as-of调整链均未建立。

现金、送股、转增、配股及增发、拆并股、换股/吸收合并/退市承接、更正/取消分别保留覆盖缺口。现金应收与实际到账不同，股份权益与可交易日期不同，配股有认购缴款选择；不能只改变价格而忽略数量及现金账。股本存量变化不是旧持有人获赠股份的直接证据。

## 身份与指数：代码表示、证券承接、成员关系分开

[身份成员表](identity-membership.csv)保留两个既有边界：

- **300114→302132**：公告条款指向2025-02-17开市代码变更，主体与股份类别数量连续。BigQuant回溯新代码与CSMAR历史旧代码的283成员日价格相容，不使历史交易代码或历史名称相同；不改写原成员键，也不授予当时可知性。
- **600068→601868**：600068于2021-09-13退市，换股比例1:4.4337，601868于09-28上市；这是不同证券的权益承接，不是1:1代码别名。09-13—09-27九个成员日需要实际过渡版本，不能凭退市日期删除成员或补正常行情。独立成员来源冲突只限09-13，不外推另外八日。

605,500是成员日数量，研究分母保持2021-09-13—2026-09-11的1211会话、932代码。冻结包manifest的historical_available_at为空。当前回溯成分不能证明当时同版可得，当前成分更不能替代历史序列。调整公告的“收盘后”与下一交易会话、条件满足日、实际实施版本必须分别处理。

权重、三源稳定ID生命周期及同代码不同证券的完整历史未建立跨源合同；现有CNRDS工作簿六位SCode只作为目标代码筛选，不由其格式自行认证交易所或稳定ID。最小补证是目标代码的交易所/稳定ID映射和有效期，而非再买全市场行情。

## 财务和行业：期间、披露与更正不是同一列

[财务语义表](financial-semantics.csv)给出26条字段级/版本级审计记录。其中：

- CNRDS FRDT.Date是会计截止日期，ActlDt是实际披露日期，预约及预约变更不是报表内容修订。财务数据变动说明的本期/上期差是同比经营变动，不是同一会计期原值和更正值。CNFS说明书明确2007年前数据曾按新准则调整，更不能用会计期认定历史原始可得。
- CSMAR普通财务区分合并/母公司、差错更正标记及更正公告日期，多次日期列表没有逐次值的对应关系。银行表还含期初日期，不能全部当期末流量；八类大财务表catalog没有逐值profile及供应商vintage证据。
- CSMAR公司表四套行业分类不能混用。BigQuant行业树、行业指数映射为无日期快照；成分date和变更change_flag仍需业务定义及分类版次。变更首窗收据0行，但后十窗有事件，不能称整表空。行业行情表不是证券归属历史。

这些事实支持字段映射设计和回顾性解释，不支持把最新重述值、当前行业或当前树回填成历史信号。更强的逐值一致性需另设同科目、同准则、同报表类型、同版本样本范围；本轮没有声称完成。
