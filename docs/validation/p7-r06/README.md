# P7-R06：等敞口基准与风险调整收益

**NO LIVE MONEY · EXPLORATORY_RESEARCH · INCONCLUSIVE**

## 结论

现有证据支持“等比网格在这个窗口盈利，并优于平均敞口相邻的固定被动持有”，但**不足以支持其相对于可比较被动基准存在不依赖基准方法的正经济优势**。当对照改为事前规则明确、使用上一小时网格持仓的动态被动执行时，优势变负；因此不能把固定持有对照中的正收益差称为稳定超额收益。

| --- | ---: | ---: |
| 等比网格（B、D 相同） | 4.949997 | 4.630056 |
| 固定持有 0.12 单位 | -1.221399 | -1.248811 |
| 固定持有 0.13 单位 | -1.323182 | -1.352879 |

基础成本平均名义敞口：网格 25.778522 USDT；0.12/0.13 单位对照分别 25.055408 / 27.143358；滞后对照 25.797265。网格相对相邻固定持有的收益差为 +6.171396 至 +6.273179 USDT，相对滞后对照为 **−0.436152 USDT**。双倍成本下两者分别为 +5.878867 至 +5.982935、**−0.435302 USDT**。这不是仅由原 Buy & Hold 的较大名义敞口造成的差别，也不是网格已被证明具有独立 alpha。

## 三种不同用途的对照

### 1. 固定预算阶梯：EX_ANTE_FIXED

预先固定 0.01–1.00 单位、步长 0.01 的全部 100 个目标，不根据未来价格或窗口平均敞口确定首小时数量。首个闭合小时价格决定限价与预算，最早下一小时成交，限价单未成交部分持续有效；剩余资金保持现金。数量规则本次回顾性研究才制定，不声称历史预注册。

沿用最小数量/步长 0.01、最小金额 5 USDT、每单最多 0.1、最多持有 1 单位、总资本预算 1000、每小时整数化基础成交量的 1% 参与率、close 加减不利滑点的合成执行。买限价向下、卖限价向上取 0.01 tick。拆单避免留下低于最小金额的最后一单，例如 0.11 可拆为 0.08+0.03，而不是非法的 0.1+0.01。固定目标 0.01/0.02 无法满足首小时最小金额，保留为 INFEASIBLE，不视为可交易零收益账户。

所有节点完整输出于 metrics.csv。使用已实现平均敞口定位相邻两个节点是**事后比较选择**，不是用事后信息调节建仓规模；没有按收益选节点。D ATR 平均敞口低于最小合法固定持有节点，比较标记 OUTSIDE_FEASIBLE_LADDER，不宣称它已被严格等敞口匹配。

### 2. 滞后持仓：EX_ANTE_GRID_DEPENDENT_LAGGED

小时 t 的网格最终持仓只用于 t 收盘后提交目标，最早 t+1 按下一小时 close 和不利滑点成交。每次收盘先尝试成交前一小时订单，再取消旧余单并按已知目标及收盘价格更新限价；不满足限价或成交量时不强制成交，小于合法最小单的调整保持原仓位。未开仓不预收买入成本，卖出不得超过已持有数量。

规则可因果执行，但信号来自网格，是**依赖网格持仓历史的动态对照，不是独立 Buy & Hold，也不是无需运行网格信号就能获得的收益**。它用于问“在几乎相同的敞口路径下，网格原成交安排是否增加了价值”，不能解释为独立策略发现。它不精确匹配每个小时敞口，也不抹掉一小时延迟、交易限制或成本。

### 3. 精确路径归因：POSTHOC_ATTRIBUTION

posthoc.csv 给出恒等式：

`净收益 = Σ(上一小时实际库存 × 本小时收盘价变化) + 执行参考价时机项 − 手续费 − 滑点`。

这是对已实现敞口路径的会计重构，**不是**按当小时网格成交反向生成的可执行被动策略。原研究用同小时 close 执行，扣除不利滑点后，执行参考价时机项仅为浮点舍入量；基础等比网格的价格路径收益 5.305000，减手续费 0.142004 和滑点 0.212999，得到 4.949997。双倍成本对应 5.340000 − 0.283987 − 0.425957 = 4.630056。不能把 5.305000 的未扣费归因量与网格净收益排序。

## 闭环与残余库存：两个解释坐标

基础等比网格完整 FIFO 闭环净收益 **5.115978 USDT**，残余库存 **−0.165981 USDT**，合计 4.949997。压力场景为 **4.818029** 与 **−0.187973**。正收益来自已实现闭环，而不是正的期末库存贡献；完整闭环与风险退出、未完成买入批次的部分卖出并不是同一概念，各策略原分类都保留在 metrics.csv。

FIFO 解释哪些买卖批次实现收益；小时持仓归因解释哪些价格变化在持仓时被捕获。这两者是同一盈亏的不同分解，不能相加，也不能由“闭环盈利”推出“闭环在其他行情可重复”。滞后对照表中的 sold_fifo_net 只是所有 FIFO 卖出匹配收益，不冒称完整网格闭环。所有残余库存按期末 close 估值，不虚构免费的期末平仓。

名义敞口使用每小时末库存乘 close。资金占用为已持有库存的入场成本加未成交买单预算预留（买单预留含费用），不是最大市值敞口。基础等比网格最大名义敞口 63.144 USDT、最大资金占用 173.760763；滞后对照分别 63.285、62.646564。相似平均敞口并不意味着所有挂单预留、尾部风险和资金路径完全匹配。固定持有 0.12/0.13 的最大回撤约 0.5981%/0.6479%，网格约 0.4335%，滞后对照约 0.4189%。不据回撤更低宣称风险调整优势。

## 六项判断

1. **优于现金：是。** 两个成本场景等比网格均为正。
2. **优于可比预算固定持有：是，限此窗口。** 完整阶梯相邻节点均亏损；不使用未来信息决定各节点仓位。
3. **相近敞口优势仍存在：取决于方法。** 固定持有对照为正差，几乎同平均敞口的滞后动态对照为负差。
4. **主要来自闭环而非期末库存：是。** FIFO 残余贡献为负。
5. **成本加倍是否改变：不改变等比网格的定性结论。** 它仍盈利、仍胜相邻固定持有、仍落后滞后对照。其他模式完整保留，压力场景不复用基础持仓路径。
6. **基准方法是否明显改变结论：是。** 因此对“相对于可比较被动基准存在正经济优势”的最终回答为 **INCONCLUSIVE**。

## 研究局限

只有一个历史窗口、一个标的，无法区分可重复闭环优势和该窗口的库存时机收益。平均/最大敞口、小时波动或最大回撤都不是完整风险匹配；固定持有不能匹配网格持仓时段，滞后对照不是独立信号。原数据与上市证据的 PIT_UNVERIFIED、HFQ_UNVERIFIED、LISTING_UNVERIFIED 及历史探索性使用边界继续保留。执行基于历史小时 close、成交量参与率和合成滑点，不是盘口可成交性证明。此次没有参数优化、窗口筛选、独立新样本验证或资金费整合；**正闭环证据不升级为已证明稳定超额收益**。
