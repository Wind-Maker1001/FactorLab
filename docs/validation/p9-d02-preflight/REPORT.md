## 缺失、适配器损失和证据是不同问题

- **来源缺失**：3,320个证券日同时没有行情键和状态键；另外260个已有行情键的会话缺open/close，261个供应商停牌会话没有可验证真实收盘。有限OHLC关系异常、重复来源键及有记录但来源身份缺失均为0。停牌重复价、零量或缺量不被解释为真实成交价。
- **来源有状态但适配器丢弃**：`st_status=2`共250证券日，000046为189、000540为38、600466为23；其中当日成员26日，全属000540。原适配器只接受0/1，不在本任务泛化映射2。其余52个st_status=1是现有适配器支持值。
- **来源可读但语义/消费合同未确认**：`is_risk_warning=1`共302证券日，有原码但当前适配器不消费；price_limit_status、exdr另列枚举库存，不能以字段可读替代经济语义认证。枚举2的供应商通用语义也未认证，定向发行人事实不能升级为全证券字典。
- **已有独立证据**：11条P9-D01候选全部经原加载器验证manifest字节、原值、公告文件和前序观察分片。002408四日各有停牌确认与独立估值候选；000540/2023-05-08另有is_st、事后成交确认和历史价格输入候选。覆盖不向其他证券、日期或字段传播。

`KNOWN_NONTRADABLE`表示供应商suspended=1的日度非交易状态，不把全部261行都升级为独立公告认证。四日carry候选属于已实现且可校验的具名政策，但**原P9-01冻结合同没有批准消费它**，故产物 `approved_for_frozen_p9_01=false`。未知估值不被自动前填。

涨跌停所需pre_close、upper_limit、lower_limit逐字段检查：9,960条缺失输入警告来自3,320个无行情键会话，每字段各一条；不据此授权有价格的卖单成交。所有风险条目可重叠，不能把条目相加当独立证券日。

## 如何给后续研究消费

本结果统一为 **EX_POST_DATA_DIAGNOSTIC**，公开风险表只允许 `BLOCKING_WARNING` / `VALUATION_EVIDENCE_INDEX`。严禁根据未来停牌、缺价、退市候选或完整性改变信号日候选池、模型目标、权重、调仓时钟或证券过滤。

**SIGNAL_TIME_KNOWN_INFORMATION**必须由独立历史时点合同提供。当前P9-D01仅000540指定is_st事实具有相应事前证据资格；其余事后全日状态和估值候选不能产生交易许可。

最小后续改动是：

1. 为002185、600095、601615的精确缺口补充发行人停复牌证据与前序观察身份，并在新研究版本显式选择估值政策。
2. 将000540、000046、600466的原枚举保留至诊断接口，取得版本化供应商语义；仅在已验证范围消费定向is_st，不将所有2自动设为true。
3. 后续估值接口分开传递真实成交价格与模型估值对象、来源日、证据及资格，不向raw_close注入carry。成员退出后残仓继续观察，缺少退市/换股合同则阻断相应解释。
4. 如要确认特定卖单能力，再补对应盘口/队列或明确既有保守日线研究合同；预检和日度成交量都不能替代订单证据。
