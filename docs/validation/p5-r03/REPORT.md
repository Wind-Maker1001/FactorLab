# P5-R03：真实配对的历史统计证据

`P5_R03_REAL_STATISTICAL_EVIDENCE`

`NO LIVE MONEY / PIT_UNVERIFIED / HFQ_UNVERIFIED / FORMAL_ADMISSION_BLOCKED`

## 结论

在事先固定的12对经济相关股票、2015—2018年CSMAR真实历史序列中，
72个候选×折只有 **1个名义通过**，逐折12重Bonferroni敏感性下为 **0个**。
找到的是局部训练期统计关系，不是稳定的样本外套利证据。

唯一通过的是工商银行/建设银行（601398.SH / 601939.SH）第一折：
训练2015-01-05—2016-12-16，共478个联合有效观测；价格相关0.929448，
Engle–Granger统计量−4.086608、p=0.005383，残差ADF p≈0.000052，
对数模型截距0.659586、beta=0.596482，分半beta漂移0.326423。
Bonferroni门槛0.05/12≈0.004167，因此不通过校正敏感性。

冻结该模型后，测试2017-04-05—2017-07-04的重新拟合EG p=0.259577，
冻结残差ADF p=0.805620，测试期拟合beta相对训练漂移约69.13%。
测试诊断不参与入选或修改参数；后续五折该对全部被训练筛选拒绝。
这不支持关系稳定延续。

默认入场|Z|≥2、退出|Z|≤0.5或穿零、最多观察10 session：
该入选折产生4个不重叠完整观察事件，仅1个恢复（25%），恢复耗时2 session。
阈值1.5为2/5恢复（40%，恢复时间中位5.5、P90 7.5 session）；
阈值2.5为1/2恢复（50%，恢复8 session）。这些小样本差异不是调参依据。
Z恢复可能来自滚动均值移动，并不等于原始经济价差盈利恢复。

## 固定范围、时间隔离与拒绝对照

候选及经济联系见研究配置，包含银行、保险、石油、煤炭、证券、铁路施工、钢铁与水泥。
名单在提取和检验价格前固定，不穷举跨行业组合，不用测试结果替换证券。
当前导出能覆盖的长期存续证券构成有界案例研究，不代表无生存偏差的全市场样本。

24只证券共23,400条原生观测。信号为已审字典定义的CSMAR `Adjprcwd`
（含现金红利再投资的可比收盘，元/股），不是实际成交价。
原生`Filling`假日行排除，停牌/填充交易状态置缺失，不前向填补；
共同日历是配置证券观测日期的并集，不宣称交易所完整日历。
上市边界仅记录首末有效观测，不将其当成已认证上市/退市日期。

每对使用相同Expanding Walk-Forward：初始训练24个月、验证3个月、测试3个月，
步长3个月，purge/embargo各12 session，实际标签边界仍由原splitter审核。
共6折，测试覆盖2017-04-05—2018-09-28；数据尾部不足完整名义折，不补短折。
训练OLS每折冻结，Z采用此前30个session，不含当日归一化观测。
验证期只记录固定阈值诊断，没有收益目标或阈值选择。

72行训练筛选中：26行EG拒绝、29行对冲比例不稳定、16行完整率不足、1行通过。
完整率不足保留为不适用，不删日期以制造合格面板；钢铁重组等经济语义变化
仍是结构性解释限制，未将其强行交易。可计算的对冲稳定性拒绝也保留EG/ADF统计。

有35个候选×折同时满足价格相关≥0.8、训练EG p>0.05且被拒绝。
例如中信证券/海通证券第一折：相关0.953410，EG p=0.538745，
beta分半漂移0.583150，因此拒绝；测试EG p=0.918475。
高相关、甚至名义残差ADF较小，都不能替代EG与稳定性筛选。
全部候选与拒绝结果见selections.csv，样本外诊断见diagnostics.csv，
不只报告最有利配对。拒绝组价差观察明确标记为诊断，不发送交易指令。

名义p值不是盈利概率。逐折12对Bonferroni只是预定敏感性，未将跨折
重复使用历史、短测试窗口低检验力、候选经济联系事前判断包装成独立确认。
短窗重新估计beta与EG用于描述，不能反过来替换冻结模型。

## 为什么不输出收益

`HISTORICAL_TRADABILITY = UNKNOWN`

`BORROW_ASSUMPTIONS = SYNTHETIC`

可比再投资价格不能直接作为固定股数双腿的开盘成交价和空头负债mark。
现有证据未给出两腿完整公司行为权益、空头补偿/拆并股负债调整与历史借券合同。
因此入口在调用交易账户前阻断，不计算收益、最大回撤、Sharpe、成交及拒单，
也不把“未运行”写成零成交或零收益。历史券源、召回、融券资格和费率均UNKNOWN。

费用/滑点/借券费敏感性网格留在配置，但为NOT_COMPUTABLE：
没有经济一致的基础损益，不能通过改变费率生成可信成本曲线。
借券数量上限、保证金、单腿成交和强退假设不实例化，因为没有执行账户；
不是默认无限券源、零费率、零保证金或原子成交。

这不妨碍独立统计结论：当前案例仅出现一个未能延续的名义关系，
没有得到多重检验后可靠且样本外稳定的配对证据。
