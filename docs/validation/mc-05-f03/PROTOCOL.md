# MC-05-F03 事前方案

F03 配置引用 F02 冻结定义，继承经认证的 NVDAUSDT 公共快照、模型参数、历史可用时间、模拟起点、Grid 参数、风险规则和成本。三个模型按固定顺序覆盖全部种子后才有资格扩档。每种子按路径 ID 取嵌套前缀 0–15、0–31、0–63。生成器与批大小维持 F02 语义。正式档位以三种子同时完成为准。预校准与串行经济对照不进入正式分母。F02 冻结资料用于核对，本轮重新回放全部正式账户。

并行预校准固定种子 1729 的前八个路径，每模型一批，各自计时。正式执行固定八个 worker，采用 900 秒预算，保留至少 1.2 安全系数和 15 秒写出储备。记录全进程树 CPU、采样峰值 RSS 与临时文件，按当前内存及空间判断完整组是否准入。源快照不进入新证据目录。失败组的诊断行在已完成组的边界之外保留。

## 收敛标准

每个模型、种子、条件组及尾部水平分别判定。两档相邻变化和最终种子极差的上限均为 0.5 个百分点。尾部名义质量与加权 Kish 有效数均须至少 20，VaR 和 CVaR 的点态 95% 区间须有限且总宽至多 2 个百分点。损失及参与比例点态 Wilson 区间宽度上限 20 个百分点。缺少任一个计划档位、条件样本或必要区间，判为尚未建立收敛。逐种子报告区间、条件分母及最大路径权重。仅同一模型可另列三种子合并点估计。

VaR 沿用 MC-02 线性样本分位数及二项次序统计区间。CVaR 沿用分数权重最差尾均值，另报仅从经验支持集重采样的 999 次区间；经验区间不充当未观测尾损失的精度证据。没有独立损失上界时保留 CVaR 无界上端点。描述性种子差异与区间均针对同一固定生成模型，参数和金融校准的不确定性单独解释。

固定串行对照为每个模型种子 1729、路径 0。金融诊断冻结 Grid，观察活跃订单与价格、实际风控证据、前一时点库存乘以价格缺口、状态块边界和历史块内依赖。条件样本只用于该条件下的结论。扩档、参数和判据均不由区间或损益结果决定。
