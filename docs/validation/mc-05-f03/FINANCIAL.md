# MC-05-F03 金融解释

FINANCIAL_NOT_ESTABLISHED。NO LIVE MONEY。

以下诊断只使用每个模型最后一个已完成的完整档位，每个 Paper 账户覆盖 168 小时。各模型风险和成交分别计算。期末 NAV 与库存金额以 USDT 计。

零成交账户中，接纳的买单来自初始几何网格。该配置到期不重挂，突破会暂停并撤单，反向订单要等首笔成交。触价按晚于提交的小时收盘价加实际买方滑点与限价比较，撤单确认当小时仍属于报价候选检查范围。表中前三个原因列互斥，其他列可重叠。活跃时未触价支持报价未满足成交条件，TTL 后触价反映期限删去了后来可能的报价机会。突破与拒绝列给出策略或控制侧事件。撤单后的触价只描述随后价格，成交候选还受容量、最小名义金额与权威准入影响。

期末 NAV 含按最后小时收盘价标记的全部未平仓头寸。FIFO 库存净损益把未平仓买入费用分配到剩余批次，账务未实现盈亏使用平均入场价。两列都是跨独立账户的金额加总。完成闭环的收益与库存标记变化须结合 FIFO 归因阅读。

| 0 | 66 | 41 | 30 | 1000.0715 | -9.9691 |
| 1 | 63 | 49 | 49 | 997.3846 | -167.0404 |
| ≥2 | 63 | 62 | 62 | 991.4733 | -540.6227 |

## 研究使用范围

本轮可以比较固定 Grid 规则在三种指定的价格生成机制下的参与率、敞口和已标记库存损失。参与组是在成交或持仓后形成的子总体。跨模型风险差异同时包含价格机制和敞口差异。把样本扩档、逐种子离散和各条件组尾部支持结合起来，才能评价模拟误差。

实盘 168 小时损失概率、可交易容量和资金配置需要独立市场证据。小时收盘价与固定合成容量的 Paper 实验只覆盖本文的成交模型，资金费未模拟。现有路径依赖同一市场历史校准，模型内重复模拟无法缩小模型与校准不确定性。

## 后续研究的独立路径与成本

每个模型、种子、条件组达到名义尾部质量 20，至少需要 400 个有效账户支持 95% 尾部，至少需要 2,000 个有效账户支持 99% 尾部。下面用二项模型规划更有余量的规模，使实际观测达到目标尾部条数的概率至少为 95%。条件组用三个种子中最小的单独 95% Wilson 参与率下限，再乘以 5% 或 1% 作为每条独立路径的尾部命中概率。成本按每模型在相同并行度下的固定账户预校准速率估算，包含三种子和预校准安全系数。Jump-down 用包含进程池冷启动的首批速率外推，长批次的墙钟和 CPU 估算偏保守。CPU 是全进程树总时长。证据量按预校准的每账户观测值外推。
