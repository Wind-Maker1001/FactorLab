# P10-11 外部策略接入验证

基线为 `388a8ee0f28e4b90ee7dbb20403a29c7fe085898`，工作分支为 `feat/p10-11-strategy-integration`。外部包沿用 StrategySpecV2、DecisionV2、StrategyPackage、隔离 worker 和 DeploymentStore。工程测试使用合成数据和离线账户夹具。

## 审计与实现

| 路径 | 保留的合同与接线 |
| --- | --- |
| V1 / V2 协议、加载器与 worker | V1 及原有 V2 包沿用预加载路径。新轻量包可使用标准库执行。安装、校验、描述与决策使用包内固定源码和工件。 |
| 市场数据 | Alpaca 与 Binance 使用各自已有的行情历史。事件单列只读参考，包只取得声明窗口。DataHub 扩展要求来源、数据版本和历史可用时间。 |
| 部署生命周期 | 以已有实例和 package ID 绑定运行时，继续使用切换、迁移、幂等决策收据和回滚。缺少输入暂停相关实例，包和 worker 错误以实例状态呈现。 |
| 模型版本 | 训练截止和生效时间随工件摘要入包。模型切换测试验证旧收据保持版本身份、重启与回滚。 |
| Native V69、资金与执行 | V69 原生接口、市场资格与现有订单和资本归属合同继续由现有路径处理。参考资产只加入行情请求。 |
| Champion 消费 | 选择凭证仍绑定期望的活动版本、证据、实例及包身份。安装和离线执行验证只给出软件结果，金融资格与运行版本选择另由各自的合同决定。 |

## 离线回归与审查

Windows Python 3.13 首轮运行了 143 项协议、部署、Alpaca 多资产、原生 V69、Binance 宿主、V1、S04 和 Champion 相关用例，139 项通过。四项失败来自资金分配、运行时绑定及读取权限的测试夹具。按实际调用合同修正夹具并加入不兼容模型用例后，复验覆盖外部策略、Binance 宿主和 S04 包故障的 23 项用例。另有 36 项固定网格、自适应网格、隔离执行及恢复用例通过。

代码审查重点是参考行情和交易权限分别流经不同事件字段，参考资产解析不写交易归属，旧模型收据在版本切换后仍可读取，以及包故障不会让其他已登记实例在启动时退出。回归测试包含参考 K 线两种到达顺序、非可交易参考 ETF、DataHub 历史可用时间、模型形状校验、同一决策时点重放、状态迁移和回滚。

PR 的可信验证由目标分支现有工作流生成。Windows 本地回归和 Linux x64 测量是独立的软件验证记录。

Linux x64 用同一套离线夹具运行了 31 项定向用例，涵盖外部策略、Alpaca 日历与数据、原生 V69、Binance 实例宿主。首轮 V69 暴露 pandas 初次本地化时读取系统时区文件的问题。worker 在受信初始化阶段预热已声明的纽约交易日历，策略运行时继续使用原有 I/O 限制。修复后 31 项全部通过。

## Linux x64 资源测量

Python 3.13，WSL Debian x86_64，源码复制到 Linux 原生文件系统。`taskset -c 0,1` 固定两个逻辑 CPU，`ulimit -v 1048576` 为各进程设置 1 GiB 地址空间上限。每行使用新进程执行一次 `python -m examples.external_strategy.run <示例> <输出目录> --measure`。加载包含校验、worker 描述和运行时指纹，决策包含新 worker 启动和指纹校验。预热表示构造声明长度的合成行情事件。

| 示例 | 加载耗时 | 加载峰值 RSS 父 / worker | 预热投影耗时 / 父进程峰值 RSS | 单次决策耗时 |
| --- | ---: | ---: | ---: | ---: |
| A 多资产 | 56.20 ms | 21,956 / 21,572 KiB | 0.06 ms / 21,956 KiB | 47.05 ms |
| B 只读 ETF | 47.91 ms | 20,984 / 20,344 KiB | 0.07 ms / 20,984 KiB | 46.37 ms |
| C 模型 1 | 50.02 ms | 20,992 / 20,352 KiB | 0.07 ms / 20,992 KiB | 48.43 ms |
| C 模型 2 | 49.18 ms | 21,040 / 20,272 KiB | 0.06 ms / 21,040 KiB | 48.37 ms |

各阶段使用进程 RSS 高水位。预热阶段未抬高父进程高水位，决策阶段父进程与任一子进程峰值相加的上界为 43.2 MiB。同样的试验从 WSL 挂载的 Windows 目录运行时，决策耗时为 3.76 到 5.83 秒。现有运行时指纹需要遍历源码，执行环境应使用本地 Linux 文件系统。测量覆盖单实例短窗口与隔离 worker，双市场完整服务的长期资源结论由 P10-02 环境验证承接。

P10-04 的事件入口与数据约定见 [外部策略接入](../../strategies/EXTERNAL_V2.md)。ARM64 执行验证等待 P10-02 环境。
