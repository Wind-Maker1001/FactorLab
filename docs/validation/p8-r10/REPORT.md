## 0. 核心结论摘要与六大核心问题明确回答

- **综合统计判定**：`INCONCLUSIVE`（细化体制状态：`INCONCLUSIVE_MAINNET_BUT_REGIME_DEFENSIVE_IN_HIGH_FUNDING`）
- **主网真实资金费（18 个 Walk-Forward 样本外 7 天窗口）**：控制组 A 均值净收益 `-0.6937%`（CVaR95 `10.24%`），策略 B（WF）`-0.2100%`（差值 `+0.4837%`，Bootstrap 95% CI `[-0.9850%, +2.0813%]`，Wilcoxon `p=0.5625`），策略 C（WF）`-0.2752%`（差值 `+0.4185%`，Bootstrap 95% CI `[-0.4175%, +1.5335%]`，Wilcoxon `p=0.4609`）。
- **高资金费 / Demo 压力体制（22.97 bps/h & 48h 突发切换，同 18 个样本外窗口）**：在持续 Demo 资费压力下，A 均值净收益暴跌至 `-10.2578%`（CVaR95 `38.55%`），B（WF）通过因果资金费门控与退出机制将其收敛至 `+0.0000%`（CVaR95 `0.00%`，Wilcoxon `p=0.0312`）；在 48h 突发高资金费切换体制下，A 为 `-8.2101%`，B（WF）为 `-0.4324%`（差值 `+7.7777%`，Wilcoxon `p=0.0312`），C（WF）为 `-6.2919%`（差值 `+1.9182%`）。

### 对任务六大核心问题的明确回答

1. **资金费过滤是否改善净收益？** **分体制与分机制结论**：(a) 在真实 Binance 主网历史资金费（均值 `0.73 bps/8h`，57.5% 为 `0`）下，资金费总额远小于方向性盈亏，策略 B（WF）相对控制组 A 的样本外净收益差为 `+0.4837%`（95% CI `[-0.9850%, +2.0813%]`，Wilcoxon `p=0.5625`），**没有稳健统计证据表明其在主网常态费率下能创造稳定正超额收益**（主网下 B 与 A 均值净收益均为负，且纯入场过滤 `B2` 几乎与 A 无异）；(b) 但在**高资金费体制**（如官方 Demo 实测 `22.97 bps/h` 或 48h 突发高资金费切换体制）下，策略 B 显著削减了尾部失血与最大回撤（持续 Demo 资费下 OOS 改善 `+10.2578%`，`p=0.0312`；48h 突发切换体制下改善 `+7.7777%`，`p=0.0312`）。**核心拆解**：在突发高资费切换体制下，**仅靠开仓前入场过滤（`B2`，全期 `-27.01 USDT`）几乎无法挽救已建仓位**，真正起决定性保护作用的是**持仓期资金费/滞留退出时机控制（`B5`，全期收敛至 `-1.52 USDT`，CVaR95 从 `32.16%` 降至 `5.01%`）**；其本质是防御性风控护栏，而非主网常态下的 Alpha 来源。
2. **自适应网格是否优于固定网格？** **没有充分证据支持全面优于固定网格**。在主网样本外 18 窗中，策略 C（WF）相对固定网格 A 的均值净收益差为 `+0.4185%`（95% CI `[-0.4175%, +1.5335%]`，Wilcoxon `p=0.4609`），CVaR95 从 `10.24%` 变为 `9.45%`；Monte Carlo 突发高资金费体制下，`moving_block_bootstrap_24h` 中 `C5` 的均值收益与 P95 最大回撤逊于 `A`，而 `jump_stress_downside` 中 C5 均值收益更差、P95 最大回撤略低，风险指标并非单向改善。宽幅自适应在高波下跌期可通过延迟触发买单或极端波动保护降低部分残仓暴露，但同时降低成交率与资金利用率，且无法根本消除单边下跌或高资金费下的残仓风险。
3. **改善是否具有样本外支持？** 主网真实费率下，B 与 C 在净收益维度均**未**达到 `p < 0.05` 且 95% Bootstrap CI 严格大于 0 的样本外显著改善（仅 B 的滞留退出带来了样本外回撤缩减 `+1.15%`, `p=0.0312`，代价是在 Fold 2/Fold 3 反弹行情中因提前退出跑输 A `-2.07%` 与 `-1.67%`）；高资金费/突发切换体制下，策略 B 的**尾部风控改善**在 6 折 Walk-Forward 汇总（18 个 OOS 窗口）中仍有统计支持，但主要体现为及时空仓/止损减亏，而非提高正向盈利能力；这不表示每折单独达到显著性。
4. **是否存在明显过拟合？** 见第 6 节参数稳定性与 IS/OOS 对比。主网体制下全 12 个 B/C 预声明参数的 IS 与 OOS 排名 Spearman 相关系数仅 `+0.4198`（`p=0.1743`，不显著），存在明显体制敏感性与样本外衰退信号：训练窗唯一正收益候选 `B4`（IS `+0.1340%`）在样本外转负（OOS `-0.2100%`，衰退 `-0.3440%`）；而策略 C 中 IS 最差之一的 `C4`（`-1.7243%`）在 OOS 反成最佳（`-0.0757%`）。虽然本实验已将搜索空间严格限制在每类 6 组预声明参数，参数排序仍难以跨市场体制保持稳定，若扩大调参自由度将有显著过拟合风险。
5. **哪个策略值得进入下一轮官方 Demo 对照测试？** **`B_FUNDING_SENSITIVE_GRID`（仅作为高资金费防御性止损/规避护栏对照，而非已验证的正 Alpha 策略）**。具体建议：在推进任何线上变动前，**先待 R09 完整 F11/F08 生命周期模型合并后完成统一模型复验**；若在官方 Demo（实证已确认周末存在 `22.97 bps/h` 极端资金费失真）开展下一轮小预算对照测试，仅建议将**策略 B 的因果高资金费入口门控 + 持仓资金费/滞留退出守卫**作为防御性风控层与控制组 A 配对观测，不建议将波动率自适应网格 C 纳入下一轮 Demo 晋级。
6. **最终规范判定**：`INCONCLUSIVE` —— 在当前离线基线（`NO_F11_NO_F08_STRANDED_POSITION_BASELINE`）与 193 天真实主网历史数据下，**尚无稳健样本外证据证明固定网格、资金费敏感网格或波动率自适应网格能够长期获得稳定正超额收益**；资金费过滤与持仓退出的真实经济价值仅体现为极端高资金费体制下的防御性尾部风险护栏。
