# P7-R14：动态 Grid 风险预算配对研究

`NO LIVE MONEY / FINANCIAL_NOT_ESTABLISHED`

## 风险得到压缩，但没有建立状态识别的独立经济增益

B 在冻结跳跌场景中减少损失和回撤，同时显著降低实际暴露、参与率并增加零成交。两个状态场景的平均收益也下降。静态低暴露对照未在评价期形成同平均暴露，因此不能把剩余差异归因为市场状态分类提供的 Alpha。

研究使用相同价格数组、初始权益、交易成本、容量、订单和 FIFO 规则，完成 **54 条评价路径 × 3 组 + 12 个独立校准账户 = 174 个账户**，耗时 **709.272 秒**。全部亏损和零成交路径均保留。

## 执行、退出和对账

所有 174 个账户的 FIFO 对账最大残差 **1e−24**，终值与导出最大差 **1.14e−13 USDT**，手续费差 **2.99e−16 USDT**；完整数量、费用、滑点、库存和成交次数检查见 [checks](frozen/checks.json) 与 [账户摘要](frozen/reconciliation.json)。

正式面板没有触发库存超预算的风险退出，风险退出成交数量和未完成退出数量均为零；这不是降预算已成功清仓的证据。容量不足、部分退出、撤单前成交及确认后库存退出由定向测试覆盖。原基准突破规则为 pause，因此下跌压力仍有真实残余库存亏损，未假设期末无滑点清仓。

完整 [paths.csv](frozen/paths.csv) 包括期末 NAV、净收益、最大回撤、实际成交量/名义额、费用/滑点、平均/峰值库存、平均/峰值名义与 NAV 暴露、FIFO 平均/最大年龄、风险退出及未完成退出、残余亏损、利用率和零成交。资金利用率为平均名义暴露/初始权益；小时快照等权，含初始锚定小时；FIFO 年龄沿用原数量加权口径。[paired.csv](frozen/paired.csv) 保留 B−A 和 B−静态的逐路径差。

[尾部代表案例](frozen/representative-tails.json) 按各模型 A 最差 NAV 与 B−A 最大退化预定义选择；历史状态退化例为路径 10，高波动持续为路径 2，跳跌为路径 2。没有保存全量价格张量或账户 SQLite。[原研究评价](frozen/evaluation.json) 保留既有 ResearchEvaluation 输出。
